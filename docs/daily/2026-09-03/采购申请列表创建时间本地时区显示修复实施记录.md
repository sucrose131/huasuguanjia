# 采购申请列表创建时间本地时区显示修复实施记录（2026-09-03）

日期：2026-09-03
对应需求：采购申请单列表时间展示
关联：`docs/daily/2026-08-25/消息中心与审批入库消息实施记录.md`（后端 UTC Instant，前端本地时区格式化）

## 一、问题

- 现象：采购申请列表「创建时间」显示的是 UTC 墙钟（通常比北京时间慢 8 小时），没有按浏览器本地时区转换。
- 根因：列表走共享页 `BusinessDocumentPage.displayCell`，`kind === 'datetime'` 对 ISO 字符串做 `replace('T',' ').slice(0,16)`，把 `2026-09-03T08:32:00.000Z` 直接切成 `2026-09-03 08:32`，丢掉时区信息。
- 关联订单弹窗「生成时间」虽走 `dateText`，但未带时间参数，只显示日期。

## 二、改动

| 对象 | 内容 |
| --- | --- |
| `apps/web/src/utils/format.ts` | 新增 `dateTimeText`：UTC Instant → 本地墙钟，精确到分钟 |
| `BusinessDocumentPage.vue` | datetime 列改用 `dateTimeText`，采购申请等业务单据列表一并生效 |
| `PurchaseApplicationOrderPreviewDialog.vue` | 关联订单「生成时间」改为本地时区日期时间 |
| `采购申请拆单生成采购订单界面与字段映射.md` | 补充时间展示口径 |

无数据库、API、字典变更；后端仍原样返回 UTC Date。

## 三、验证

- `format.spec.ts`、`p2-dialog-consistency.spec.ts` 覆盖 UTC 转本地、禁止 ISO 切片回归。
- 浏览器：打开采购申请列表，核对「创建时间」与本地时区一致（UTC+8 下比接口 ISO 的小时数多 8 小时）。
