# 登录页医务操作指引实施记录

日期：2026-09-03
关联：登录页增加医护操作指引，点击查看 OSS 培训手册。OSS 路径改由数据字典维护。

## 一、已确认口径

未登录用户在登录页点击「医护操作指引」，打开字典值中的 OSS 对象。当前项：

| 字典类别 | 字典名称 | 字典值（OSS 对象键） |
| --- | --- | --- |
| `login_operation_guide` | 医护操作指引 | `documents/华溯管家医院业务操作培训手册-20260903.pdf` |

接口只读取该字典类别下的合法 PDF 对象键。不限定必须在 `documents/` 目录。不新增表或字段。

## 二、字段 / API / 数据库映射

| 页面操作 | API | 权限 | 数据 |
| --- | --- | --- | --- |
| 登录页展示入口 | `GET /public/operation-guides` | 公开 | 读字典名称和值，不写库 |
| 点击医护操作指引 | `GET /public/operation-guides/file?value=` | 公开 | 按字典值同源输出 PDF，不写库 |

## 三、改动

| 文件 | 改动 |
| --- | --- |
| `20260903_login_operation_guide_dictionary.sql` | 新增登录页操作指引字典；值为 OSS 对象键 |
| `attachments.service.ts` | 从字典值读取对象键并输出预览 |
| `public-documents.controller.ts` | 公开列表和 `file?value=` 预览接口 |
| `Login.vue` | 登录按钮下方按字典展示入口，弹窗 iframe 在线预览 PDF |

## 四、验证

- 后端单测覆盖字典读取、对象键校验、文件缺失、OSS 未配置。
- 前端契约测试确认登录页调用公开字典接口。
- 本地 `hspsi-dev` 已执行上述 SQL。
- 浏览器验收：登录页显示「医护操作指引」，点击弹窗在线预览 PDF。

## 五、遗留

1. 目标库执行 `20260903_login_operation_guide_dictionary.sql`。
2. 若 OSS 中该对象尚未上传或对象键与字典值不一致，预览会失败。
3. 手册更新或新增指引时，改字典名称和值即可；`dict_value` 最长 100 个字符。
4. 字典值可被有字典维护权限的人改成桶内其它 PDF，登录页会公开预览，需控制字典维护权限。
