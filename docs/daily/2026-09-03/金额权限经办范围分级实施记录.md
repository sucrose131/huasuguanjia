# 金额权限经办范围分级实施记录

> 需求：金额白名单在「可视/可修改」下再分两种等级——只能看见自己经办单据的金额 / 可以看见权限内所有单据的金额。
> 方案：`docs/global/plans/金额权限经办范围分级方案.md`（2026-09-03 业务负责人确认口径后实施）
> 分支：`feature/0902-oa-cancel-master`

## 1. 业务口径（2026-09-03 已确认）

- 「自己经办」= 单据 `created_by === 当前用户`。
- 「可编辑」同样分「自己 / 全部」两档。
- 存量白名单用户默认「仅自己经办」（`amount_scope` 默认 1，ADD COLUMN 存量自动补 1）。
- 商品档案成本/售价等主数据金额不参与 own/all 分级，仍由「查看能力」整体控制（goods 端点豁免）。
- 金额范围是字段级授权，仍与既有组织/仓库数据权限取交集。

## 2. 数据库

- 迁移：`database/migrations/20260903_user_amount_access_scope.sql`
  - `hspsi_sys_user_amount_access` 新增 `amount_scope tinyint NOT NULL DEFAULT 1 COMMENT '金额数据范围 1=仅自己经办 2=权限内全部'` + CHECK(IN (1,2))。
- 已执行于本地 `hspsi` 库；`prisma/schema.prisma` 同步字段并已 `prisma generate`。
