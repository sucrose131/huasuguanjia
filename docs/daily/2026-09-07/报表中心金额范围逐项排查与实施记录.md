# 报表中心金额范围逐项排查与实施记录

## 1. 需求与执行边界

执行规则：报表金额仅允许「查看能力 + 权限内全部」；仅查看·自己、可编辑·自己、无权限全部掩码。本人单据也不能在报表中例外放行。非金额和原有组织权限不变。

方案：[报表中心金额范围统一规则](../../global/plans/报表中心金额范围统一规则.md)。分支：`feature/0907-purchase-order-edit-optimization`。数据库核对为本地 `127.0.0.1:3306/hspsi-dev`；未修改表结构、字典或用户授权，未删除历史业务数据，未提交/推送Git。
