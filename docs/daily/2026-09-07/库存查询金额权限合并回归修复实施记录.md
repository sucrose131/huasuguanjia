# 库存查询金额权限合并回归修复实施记录

## 1. 原始一级需求

在 `feature/0907-purchase-order-edit-optimization` 分支恢复库存查询金额权限：仅系统管理—用户管理中金额权限为“仅查看—权限内全部”或“可编辑—权限内全部”的用户可以查看单位成本、库存金额和库存总值；其余权限用户显示金额掩码。

## 2. 排查结论

- 原实现提交 `bd5dc0a` 已通过合并提交 `c6c6f8f` 进入分支历史，并未丢失。
- 后续合并提交 `58663f1` 在引入盘点成本快照权限时，将库存查询旧版 `@AmountScopeExempt()` 一并恢复，造成 `view·own`、`edit·own` 用户再次可以查看真实库存金额。
- 当前数据库继续复用 `hspsi_sys_user_amount_access.can_view_amount`、`can_edit_amount`、`amount_scope`，无需变更表、字段、索引或字典。

## 3. 字段、API 与实现

| 页面字段 | API 字段 | 数据来源 | 权限规则 |
| --- | --- | --- | --- |
| 单位成本 | `unitCost` | `GET /inventory/stocks`，库存金额 ÷ 库存数量 | 仅 `view·all`、`edit·all` 可见 |
| 库存金额 | `inventoryAmount` | `GET /inventory/stocks`，现有库存批次金额 | 仅 `view·all`、`edit·all` 可见 |
| 库存总值 | `summary.totalAmount` | `GET /inventory/stocks`，当前查询库存金额合计 | 仅 `view·all`、`edit·all` 可见 |

服务端将 `InventoryController.stocks` 标记为 `@AmountAllScopeOnly()`；无金额查看能力或 `amount_scope=own` 时，由统一金额拦截器将已登记金额字段置空。前端沿用现有星号掩码，不改变接口路径、请求参数或库存计算口径。
