# 盘点单据成本单价金额权限收口实施记录

> 日期：2026-09-07
> 分支：fix/20260904/lzw
> 原始一级需求：库存查询金额权限收口（bd5dc0a）后，发现盘点链路仍能反推库存价值——盘点单/盘点衍生单据详情中的成本单价未被金额范围约束。

## 1. 现象与漏洞路径

- 金额权限为「仅查看/可编辑 + 仅自己经办（own）」的用户（具盘点菜单权限即可）新建盘点单时，系统载入所选仓库全部在库批次，明细携带成本单价 `unitPrice`（库存金额/数量）与差异金额；表头另含整仓库存总值 `all_value`。
- 由于盘点单 `created_by` 为用户本人，全局金额拦截器的 own 范围按记录归属逻辑将其判为"本人经办单据"，金额放行；前端 `recordAmountMasked(form)` 同样因"本人创建"不掩码 → 单价直接可见，可反推总库存价值，绕过库存查询金额收口。
- 盘点衍生的报亏出库（loss-outputs）、报盈入库（overflow-inputs）只读详情同样展示来源盘点的成本单价。

## 2. 需求、界面与映射确认

- 口径（业务确认）：盘点单明细成本单价/差异金额，以及盘点衍生的报亏出库/报盈入库只读成本价，与库存查询 stocks 一致——金额仅在「仅查看/可编辑 + 权限内全部（amount_scope=all）」可见；own 范围不随单据 created_by 归属放行，一律脱敏为 `¥ ****`。
- 数据库：复用 `hspsi_sys_user_amount_access`；不新增或修改表、字段、索引及字典。
- API：盘点三处详情响应路径、参数与结构不变，仅按新装饰器语义在统一拦截器内脱敏。
- 业务无损：盘点保存仅提交数量（checkQty/damagedQty），差异金额由服务端以库内 `unit_price` 重算，前端掩码不影响盘点与后继报损/报盈金额核算。
