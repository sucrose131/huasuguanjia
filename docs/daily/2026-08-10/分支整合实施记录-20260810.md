## 三、商品分类选择改造

### 业务规则

- 商品不再限制只能选择叶级分类；
- 商品资料新增/编辑、商品列表分类筛选、采购单内快捷新增商品统一使用 Element Plus 树形分类下拉；
- 任意层级只要分类启用且绑定有效仓库类型，即可作为商品分类；
- 停用或未绑定有效仓库类型的分类仍不可用于创建商品；
- 分类自身的 `warehouse_type` 继续决定商品在哪些组织仓库范围可用。

### 字段映射

| 页面字段     | API 字段                     | 数据库字段                                 | 说明                           |
| ------------ | ---------------------------- | ------------------------------------------ | ------------------------------ |
| 商品分类     | `categoryId`                 | `hspsi_goods_info.goods_catg_id`           | 仍保存分类主键，不新增字段     |
| 分类仓库类型 | 分类接口返回 `warehouseType` | `hspsi_goods_info_category.warehouse_type` | 用于组织可见范围和业务仓库校验 |

### 采购商品远程搜索

- 采购申请、无来源采购订单和直接采购入库的商品下拉启用 Element Plus `remote` 模式；
- 输入商品名称、速查码等关键词后，使用 250ms 防抖调用 `GET /goods?keyword=...&status=1&pageSize=50`；
- 使用请求版本号丢弃过期响应，避免快速输入时旧结果覆盖新结果；
- 返回商品继续按当前单据已选仓库类型及其他明细的分类仓库类型过滤；
- 命中商品合并到本地选项，保证选中后和编辑回显正常；
- 搜索失败显示失败提示，不把网络失败误判为“商品不存在”；
- 保留全局同名检查和快捷新增事务规则。
