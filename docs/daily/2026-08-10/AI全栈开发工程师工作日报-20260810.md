## 二、今日完成工作

- 以 `feature/sync` 为基线整合新需求开发成果；
- 完成环境配置、项目依赖、Prisma Schema、应用模块入口及锁文件冲突处理；

### 2. 商品分类选择能力改造

- 商品新增、编辑、列表筛选及采购单快捷新增统一改为树形分类选择；
- 商品不再被限制只能选择叶级分类，启用且绑定有效仓库类型的父级分类也可使用；
- 后端继续校验分类状态、仓库类型及组织可用范围，避免仅依靠前端限制；
- 本次复用现有数据库字段，没有新增表、字段或数据字典。

### 3. 采购商品远程搜索优化

- 采购申请、采购订单和直接采购入库的商品选择改为远程搜索；
- 支持按商品名称、编码、简称及品牌检索，解决首次加载数量限制导致商品无法找到的问题；
- 增加 250ms 防抖及响应版本控制，防止快速输入时旧请求覆盖新结果；
- 保留仓库类型过滤、编辑回显和快捷新增能力；
- 搜索失败时显示明确错误信息，避免将网络异常误判为商品不存在；
- 已完成“徐福记米格玛”实际数据核对，能够正确检索并匹配对应仓库类型。

### 4. 商品名称唯一性核对

- 核对商品新增、编辑及采购快捷新增的全局同名校验逻辑；
- 确认 Prisma Schema 与迁移脚本已声明商品名称唯一索引；
- 识别出商品名称输入阶段即时提示、并发唯一键异常友好提示、华数之家同步同名处理规则及实际数据库索引状态等后续完善事项；
- 本轮以现状核对和方案确认为主，未在业务规则未统一前擅自修改同步逻辑。

### 5. 业务单据单位名称显示修正

- 新增统一的单位名称解析工具；
- 统一业务单据明细及生产出库查看、编辑弹窗的单位展示规则；
- 页面优先展示接口返回的单位名称，缺失时根据单位 ID 映射名称；
- 无法匹配时显示“—”，不再将数据库内部单位 ID 直接展示给用户；
- 数据库存储和接口提交仍使用原单位 ID，不涉及数据库结构和业务数据变更。

### 6. 部署路由与 HTTP 环境兼容问题排查

- 定位测试环境深层路由刷新 404 的原因：实际部署 Nginx 未配置 Vue Router History 回退；
- 确认仓库内 Nginx 配置正确，后续需由部署环境更新实际配置并重新部署；
- 定位“直接领用出库”点击无效的前端原因：HTTP 环境下浏览器不提供 `crypto.randomUUID()`，初始化请求键时抛出异常；
- 新增统一请求 ID 生成工具，并兼容原生 UUID、`getRandomValues()` 和无 Web Crypto 场景；
- 已替换直接领用出库、资金请求、通用出入库及 BOM 退库中的原生 UUID 调用。
