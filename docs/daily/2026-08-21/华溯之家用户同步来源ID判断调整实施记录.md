# 华溯之家用户同步来源 ID 判断调整实施记录（2026-08-21）

## 一、需求

华溯之家用户同步原先拦截来源机构 ID（`organization_id`）必须大于 0（代码为 `< 1`，业务上常说成「需要大于 1」）。`0`、`1` 只要已做机构映射，都应写入客户，不再因 ID 数值本身失败。

## 二、范围

- **本次**：去掉 `organization_id < 1` 拦截；加载机构映射时包含 `0`。
- **不改**：表结构、字典、页面；用户主键 `id` 仍须有效（`>= 1`），避免与手工客户默认 `related_customer_id=0` 冲突；未映射机构仍单条失败。

## 三、影响

| 页面/接口/数据 | 变化 |
| --- | --- |
| `huasu-home:users` 用户同步 | `organization_id` 为 `0` 或 `1` 且已映射时正常创建/更新客户 |
