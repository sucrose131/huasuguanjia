# 组织—仓库类型—商品分类主数据映射全局收口实施记录

日期：2026-08-28
对应计划：[组织仓库类型商品分类主数据映射全局收口计划](../../global/plans/组织仓库类型商品分类主数据映射全局收口计划-20260828.md)

## 一、需求理解确认

本次需求不是库存联动改造，而是创建业务单据时的主数据映射收口。

```text
组织
→ 组织下启用的具体仓库
→ 仓库类型
→ 对应商品分类
→ 分类下启用商品
→ 商品下启用 SKU
```

销售订单、采购申请、领用申请、生产 BOM 和入库创建时，不检查商品是否已有库存，不读取库存批次，不要求库存数量大于零。

商品历史 `org_id` 不作为创建单据候选过滤条件。组织对商品的使用范围由该组织实际拥有的仓库类型和商品分类映射确定。

出库、调拨、报损、盘点和库存调整仍按实际库存运行，不在本次修改范围内。

## 二、数据库和字典结论

- 表结构：无需修改；
- 字段：无需新增、删除或调整；
- 数据字典：继续使用现有 `warehouse_type`，无需修改；
- 数据迁移：不需要；
- 历史数据：本次不删除、不批量修改。

## 三、现状排查结果

### 3.1 已正确实现

- 仓库可以校验属于单据组织；
- 仓库已经配置 `warehouse_type`；
- 商品分类已经配置 `warehouse_type`；
- 商品通过 `goods_catg_id` 归属于商品分类；
- 商品与 SKU 已有从属关系；
- 商品管理页面已经具备按组织现有仓库类型限制分类范围的基础能力。

### 3.2 实施前发现并已修复的问题

- 公共商品候选查询仍额外按商品历史 `org_id` 过滤；
- 公共保存校验仍可能以商品 `org_id` 判定“不属于当前组织”；
- 通用组织数据拦截会再次对商品表追加 `org_id` 条件；
- 通用入库存在同样的商品 `org_id` 附加过滤；
- 前端公共过滤仍放行未配置仓库类型的商品；
- 各创建类模块此前未完成统一回归。

### 3.3 已确认的数据差异样本

氧源科技“生产-成品仓”的仓库类型对应分类下共有 31 个启用商品，当前接口受商品 `org_id` 条件影响只返回 23 个，存在 8 个符合分类映射但无法搜索的商品。

该样本作为实施后的固定回归用例。
