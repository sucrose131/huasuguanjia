## 一、问题描述

采购申请单（`purchase/applications`）查询栏存在两个界面缺陷：

1. 「所属组织」（tree-select）与「目标仓库」（select，依赖所属组织）筛选控件下拉没有选项；
2. 「申请日期」时间筛选控件（date-range）日历弹层显示英文（月份、星期等）。

## 二、根因分析

### 1. 组织树为空

- 查询栏由共享引擎 `apps/web/src/views/business/BusinessDocumentPage.vue` 渲染；
- 组织树数据来自 `apps/web/src/views/business/use-business-document-options.ts` 中的 `organizationTree` computed；
- 该 computed 使用一段手写递归构建，根节点匹配条件为
  `(item.raw?.parentId ?? item.parentId ?? null) === null`；
- 而组织根节点的 `parent_id = 0`（数据库默认值，BigInt 经接口序列化为字符串 `"0"`），不等于 `null`，
  导致顶层节点永远匹配不到，整棵树为空；
- 项目其他页面均复用公共工具 `apps/web/src/utils/organization-tree.ts` 的 `buildOrganizationTree`，
  该工具将 `parentId === '0'` 正确视为根节点，仅共享引擎此处的临时实现有缺陷。
- 「目标仓库」为 `dependsOn: 'orgId'` 联动字段，未选中组织时不加载；组织树为空导致无法选中组织，仓库联动自然为空。仓库自身加载逻辑（`/base-data/warehouses/options?orgId=…`）无问题。

### 2. 时间控件英文

- `apps/web/src/main.ts` 中 `app.use(ElementPlus)` 未配置 locale，应用内也没有
  `<el-config-provider :locale="zhCn">`，Element Plus 默认使用英文 locale，
  日期选择器日历弹层的月份、星期等文案显示英文。

## 三、本次修改

| 文件 | 修改内容 |
| --- | --- |
| `apps/web/src/views/business/use-business-document-options.ts` | 删除手写组织树递归构建，改为复用 `@/utils/organization-tree` 的 `buildOrganizationTree(options.orgs ?? [])` |
| `apps/web/src/main.ts` | 引入 `element-plus/es/locale/lang/zh-cn`，`use(ElementPlus, { locale: zhCn })` 全局挂载中文 locale |

## 四、影响范围

- 共享引擎 `organizationTree` 一处修复，同时生效于所有通过 `BusinessDocumentPage` 使用
  `tree-select` 查询字段的页面：采购申请、库存盘点、库存调整、库存调拨、库存报损、库存报溢、
  盘盈盘亏入库、数量/效期预警等；
- Element Plus 全局中文 locale：所有页面日期选择器、分页等组件文案统一中文化，属纯文案展示变化，不影响接口与数据。
