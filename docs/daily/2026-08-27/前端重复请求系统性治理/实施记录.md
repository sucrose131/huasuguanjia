# 前端重复请求系统性治理实施记录

> 日期：2026-08-27  
> 分支：`codex/fix-duplicate-page-requests`  
> 状态：代码完成，待业务验收

## 1. 实施内容

1. 修复共享业务单据页面在任意行操作完成后无条件刷新列表的问题；查看、编辑、配置、打开新增和跨页导航现在不会刷新原列表，真实数据变更仍保持成功后刷新。
2. 采购申请、采购订单详情统一由共享页面加载，删除表单挂载时的同详情二次网络请求；深链进入也只保留一个详情加载入口。
3. 为其他业务深链增加一次性详情交接，已取得的完整详情由表单直接消费，不缓存后续业务详情。
4. 为组织、单位、仓库、供应商、人员选项和数据字典增加按用户、按参数的请求复用；任意写请求前自动失效。
5. 移除基础资料、一般出入库、工作台、系统管理和报表通用页与 `router-view` 重建机制冲突的路由监听，消除旧实例加载与新实例挂载的双请求。
6. 调整生产出库自定义弹框：直接关闭不刷新，真正完成操作后刷新一次。

## 2. 影响范围

- 共享业务页面：采购、销售、库存、生产、领用相关单据页。
- 通用路由页面：基础资料、一般出入库、工作台、系统管理、报表中心。
- API：仅调整前端 GET 请求编排，没有改变任何后端接口。
- 数据库与字典：无变更。
