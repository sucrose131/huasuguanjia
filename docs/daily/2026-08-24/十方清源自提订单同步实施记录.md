# 十方清源自提订单同步实施记录（2026-08-24）

## 一、需求

将十方清源云库存自提单同步到本平台销售履约：销售订单、客户、发货出库、取消回库。不写收款、退款、售后。

业务确认口径见当天对话及 `docs/global/integrations/shifang-qingyuan/自提订单同步.md`。

## 二、范围

- **本次**：独立任务 `shifang-qingyuan:agent-orders`；list 快照建单；STANDARD 映射；已发货/已完成出库；已出库后取消按出库单回库，过账键 `sfqy-exit:{so_output_id}:v1`。
- **不改**：表结构、字典、普通销售订单同步、手工 HTTP 同步接口。
- **暂缓**：配货等其他云库存单据。
