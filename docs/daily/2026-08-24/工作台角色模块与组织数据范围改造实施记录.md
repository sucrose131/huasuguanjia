# 工作台角色模块与组织数据范围改造实施记录

## 一、实施目标

在不改变现有工作台视觉风格、不新增数据库表或字段的前提下，实现以下规则：

- 角色管理中“工作台—数据总览”一行的“其他业务操作”直接配置多个工作台组件；
- 角色的组件操作权限与对应业务菜单权限共同决定组件是否显示；
- 用户主组织与额外授权组织共同决定工作台数据范围；
- 金额查看继续由现有金额白名单独立控制；
- 不按角色名称写死展示规则；
- 工作台按独立组件维护，禁止重新形成通用大文件和无条件全量加载。

## 二、本次实施内容

1. 将指标卡片、采购销售趋势、库存健康、待办预览、待办列表、消息摘要、消息中心、快捷功能拆分为独立组件。
2. 新增统一的工作台类型定义和快捷入口配置，页面不再散落硬编码入口。
3. 快捷入口同时校验页面查看权限和对应新增权限；无权入口不展示。
4. 新增 9 项 `dashboard:overview:widget:*` 操作权限，直接展示在角色管理“数据总览”行的“其他业务操作”中；不新增独立的工作台管理页面或配置区域。
5. 角色组件选择随现有角色权限接口统一保存、编辑和回显，继续复用 `hspsi_sys_role_menu`。
6. 后端按“组件权限＋业务菜单权限”的交集返回展示结果，前端缺少授权结果时默认不显示，不依赖“财务”“仓管”等角色名称。
7. 工作台前端先读取组件授权，再分别按需加载指标、采购销售趋势、库存健康、待办预览和消息摘要；未配置组件不发起对应请求，单个组件失败不影响其他组件。
8. 工作台统计范围由“仅主组织”修正为“主组织＋额外授权组织”。
9. 待办根据对应业务页面权限过滤，防止用户看到无法进入处理的单据。
10. 库存预警按授权组织所属仓库过滤；库存调整通过明细仓库反查授权范围。
11. 消息标记已读使用独立的 `dashboard:messages:read` 操作权限。

## 三、字段与数据来源

本次未新增页面录入字段。展示字段继续映射现有数据：

| 展示内容      | API 字段                      | 数据来源                                 | 权限边界                               |
| ------------- | ----------------------------- | ---------------------------------------- | -------------------------------------- |
| 本月销售额    | `salesAmount`                 | `hspsi_sale_order.fact_amount`           | 销售模块权限＋授权组织＋金额白名单     |
| 本月采购额    | `purchaseAmount`              | `hspsi_purchase_order.pay_amout`         | 采购模块权限＋授权组织＋金额白名单     |
| 库存总值      | `inventoryValue`              | `hspsi_inventory_total.inventory_amount` | 库存模块权限＋授权组织＋金额白名单     |
| 待办数量/明细 | `pendingCount`、`todos`       | 现有业务单据及系统待办                   | 工作台待办权限＋业务页面权限＋授权组织 |
| 库存健康/预警 | `healthScore`、`lowStockItem` | 库存结存、预警及仓库资料                 | 库存模块权限＋授权组织仓库             |
| 消息          | `messages`                    | 系统消息及授权业务动态                   | 消息权限＋当前用户＋授权组织           |
