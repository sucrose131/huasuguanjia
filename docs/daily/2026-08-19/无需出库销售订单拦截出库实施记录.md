# 无需出库销售订单拦截出库实施记录（2026-08-19）

## 一、需求

销售订单类型为「无需出库」（`so_type=4`，例如十方清源云库存纯入库）的单据，业务上不办理销售出库。仓库人员不应在销售订单看到「直接出库」，也不能在销售出库单中选这类订单并保存。

## 二、范围

- **本次**：销售订单列表隐藏「直接出库」；出库单选择器过滤；`POST/PATCH /sales/outputs` 拒绝创建/编辑来源为无需出库订单的出库单。虚拟订单沿用原拦截文案。
- **不改**：表结构；收款/退款仍可办理；同步侧仍不写销售出库。
- **暂缓**：发货进度/发货状态展示口径是否按「无需出库」单独展示。

不新增表或字段。字典项「无需出库」沿用 `database/migrations/20260818_sales_order_type_no_output.sql`。

## 三、影响

| 页面/接口 | 变化 |
| --- | --- |
| 销售管理 > 销售订单 | `orderType=4` 不出现「直接出库」 |
| 销售管理 > 销售出库单 | 搜索/选择来源订单时排除无需出库；深链进入会提示并清空 |
| `saveOutput` | `so_type=4` 返回「无需出库订单不能创建销售出库」 |
