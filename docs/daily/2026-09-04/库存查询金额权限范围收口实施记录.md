# 库存查询金额权限范围收口实施记录

## 1. 原始一级需求

库存查询中的单位成本和库存金额，仅允许系统管理—用户管理中金额权限为“仅查看—权限内全部”或“可编辑—权限内全部”的用户查看；其他用户看到金额掩码。

## 2. 需求、界面与映射确认

- 使用人：具有库存查询菜单权限的用户。
- 页面入口：库存管理—库存查询。
- 界面：保留“单位成本”“库存金额”和库存金额合计原有位置；无权时沿用系统既有星号掩码，不新增按钮、字段或交互。
- 允许：`can_view_amount=1` 且 `amount_scope=2`（“权限内全部”）返回并展示真实金额；其中“仅查看”和“可编辑”均满足。
- 拦截：无金额权限、未配置金额权限，以及金额范围为“仅自己”的用户，服务端将 `unitCost`、`inventoryAmount`、`totalAmount` 等登记金额字段置空，前端显示星号掩码。
- 字段映射：页面 `unitCost`、`inventoryAmount`、`summary.totalAmount` ← `GET /inventory/stocks` 同名字段 ← 现有库存数量与库存金额计算结果。
- 数据库：复用 `hspsi_sys_user_amount_access.can_view_amount`、`can_edit_amount`、`amount_scope`；不新增或修改表、字段、索引及字典。
- API：`GET /inventory/stocks` 路径、参数和响应结构不变，仅撤销金额范围豁免，由统一金额权限拦截器执行最终脱敏。
