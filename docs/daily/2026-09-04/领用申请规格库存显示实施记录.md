## 一、需求与边界

- 用户：新建/编辑/查看领用申请单时，在明细「SKU/规格」列选择或查看规格。
- 现象：规格下拉只显示规格名称，没有该规格在当前组织的库存数；同一商品不同 SKU 库存可能完全不同。
- 本次要做：规格选项展示该 SKU 在当前单据组织的库存（已选仓库=该仓库数量，未选=领用可用仓库合计）；零库存标注「暂无库存」，仍允许选择。
- 本次不做：不按库存收窄规格候选；不改保存校验；出库确认仍是库存执行层。

## 二、字段映射

| 页面元素 | 业务含义 | API 字段 | 数据库 | 说明 |
| --- | --- | --- | --- | --- |
| SKU/规格下拉库存 | 该规格当前组织可用库存 | `GET /requisitions/all-goods-options` 返回 `skuStockByWarehouse`（sku_id → { warehouse_id: 数量 }） | `hspsi_inventory_total.inventory_qty` 按 (warehouse_id, goods_id, sku_id) 汇总，且 `org_id = 单据组织` | 只读展示；商品级 `stockByWarehouse` 仍为各 SKU 合计 |
