# OA 全员基础账号与多账套身份实施记录（2026-08-17）

## 完成内容

- 所有 OA 有效员工自动生成或更新进销存登录账号，手机号作为统一登录账号，初始密码为手机号后六位。
- 新增“基础申请人”角色，默认开放采购申请和领用申请；岗位字典只负责叠加额外业务角色。
- 员工缺少岗位时不再阻断基础登录，只要 OA 身份有效且有主组织即可获得申请权限。
- 新增 `hspsi_sys_user_oa_staff`，支持一个自然人账号关联多个 OA 账套员工身份。
- 单据推送 OA 时按单据所属账套选择对应员工身份，不再仅通过用户名反查员工。
- OA 同步仍不读取或修改金额白名单。
