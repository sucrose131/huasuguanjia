# 售后记录界面修复记录

> 日期：2026-08-17
> 页面：销售管理 → 售后记录 → 查看/编辑

## 需求与界面调整

- 修复查看售后记录时仍显示“添加进展”输入控件的问题；
- “售后处理进展”由时间线卡片改为 Element Plus 标准表格；
- 查看模式只显示处理时间、处理内容、处理状态、记录来源和处理人；
- 编辑模式显示进展录入区，并在人工记录行提供编辑、删除操作；
- 表格采用 `border + stripe + row-key + fixed action + overflow tooltip`，与项目表格样式归档一致；
- 窄屏下进展状态、处理时间和提交按钮改为单列排列。

## 数据与接口映射

| 页面字段 | API字段                          | 数据来源                                             |
| -------- | -------------------------------- | ---------------------------------------------------- |
| 处理时间 | `occurredAt`                     | `hspsi_sale_order_service_progress.occurred_at`      |
| 处理内容 | `content`                        | `hspsi_sale_order_service_progress.progress_content` |
| 处理状态 | `status`、`statusName`           | `progress_status`、字典 `after_sale_event_status`    |
| 记录来源 | `sourceType`、`sourceTypeName`   | `source_type`，1人工、2外部同步、3系统记录           |
| 处理人   | `handlerIdName`、`createdByName` | `handler_id`、用户基础资料                           |

本次仅调整前端展示与交互，不修改数据库结构、数据字典和API契约。
