# 授权组织与 OA 自动授权实施记录（2026-08-17）

## 一、原始需求

OA 同步后自动生成进销存登录账号、本地角色和授权组织；用户只能在已授权组织中切换当前组织，所有业务数据只按当前组织读写。金额白名单是独立的本地审批权限，OA 同步不得修改。

## 二、本次完成内容

- 将 `hspsi_sys_user_org_scope` 升级为 `hspsi_sys_user_authorized_org`，回填现有本地账号的启用主组织。
- 删除 `hspsi_sys_role.data_scope_type`，停用 `role_scope_type` 字典。
- 新增 `oa_default_staff_role`、`oa_position_role_mapping` 和 `oa_org_authorization_rule` 数据字典；全员基础角色与岗位附加角色都不写死角色 ID。
- OA 人员同步依字典全量刷新用户角色和授权组织；人员失效时同步清除。
- Redis 会话保存 `currentOrgId`，新增 `POST /api/auth/switch-organization`。
- Prisma 业务读写从“角色五档范围”改为只按单一当前组织强制过滤。
- 顶部导航增加当前组织切换；角色管理删除默认数据范围；用户管理展示授权组织。
- OA 同步账号禁止本地修改身份、角色和组织；金额白名单入口保持独立。
