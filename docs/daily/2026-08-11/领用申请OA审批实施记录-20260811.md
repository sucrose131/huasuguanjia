# 领用申请 OA 审批实施记录（2026-08-11）

领用申请在华溯管家创建并提交后同步发起薪福通 OA 审批；OA 到达终态后回调华溯管家，更新领用申请审批结果。审批通过后沿用现有规则自动生成领用出库草稿，不在审批回调时直接扣减库存。

## 五、遗留问题

1. 薪福通现有说明只给出回调业务字段，未说明入站验签、加密、时间戳或可信来源验证方式；
2. 在取得 OA 回调认证协议前，不开放无认证回调接口，避免伪造审批结果；
3. 网络超时但 OA 已受理时，需要通过 OA `busKey` 查询能力完成重试前对账，避免重复流程；
4. 当前 OA 表单的“领用人名称”和“领用人”均存在，人员控件由系统强制传值；后续可由 OA 侧决定是否删除辅助名称字段。
