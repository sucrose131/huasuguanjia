# 采购订单计价规则实施记录（2026-08-11）

## 一、需求

采购订单商品明细由原“单价 + 数量计算总价”调整为“数量 + 总价反算单价”，总价作为最终金额口径。

## 二、实施内容

- 移除采购申请明细“预计单价”“预计金额”及列表“参考金额”；
- 新采购申请的 `reference_price` 固定写入 `0`，历史数据保持不变；
- 采购申请审批生成的采购订单金额初始为 `0`，等待采购人员填写明细总价；
- 采购订单明细总价未补齐时，后端禁止“开始采购”；
- OA 采购申请表单设计移除预计总金额和参考单价；
- 采购订单明细将“采购单价”编辑框改为“明细总价”编辑框；
- 增加只读“反算单价”，随数量和总价实时变化；
- 后端校验数量和明细总价，并重新计算两位采购单价；
- 明细总价保存到现有 `total_amout`，订单总额按明细总价求和；
- 列表、详情和付款金额统一读取精确总价；
- 采购退货使用 `total_amout ÷ qty` 计算来源平均单价，避免不能整除时产生 0.01 元误差；
- 未新增数据库表、字段或字典。
