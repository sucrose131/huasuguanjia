业务目标：采购申请审核通过后，由采购人员选择供应商，按整单或选品方式人工生成采购订单。一张采购申请可以生成多张采购订单，但每条采购申请明细在有效采购订单中只能生成一次。采购人员录入明细总金额，系统根据申请数量反算采购单价。

## 五、后端业务逻辑

### 5.1 审批规则

- 采购申请审批通过只更新审批结果；
- 不再在审批通过时自动创建零供应商、零金额采购订单；
- 生产缺料自动形成的采购申请，审批通过后同样由采购人员人工生成采购订单。

### 5.2 生成接口

新增接口：

```text
POST /api/purchase/applications/:id/generate-order
```

支持：

- `generationMode=all`：把提交时全部待生成明细生成一张订单；
- `generationMode=partial`：把本次勾选的多条明细生成一张订单；
- `vendorId`：本张采购订单的供应商；
- `details[].applicationDetailId`：来源采购申请明细；
- `details[].totalAmount`：该明细的采购总金额。

### 5.3 事务和校验

后端在同一事务中：

1. 锁定采购申请并确认已审核通过；
2. 校验组织、部门、仓库、供应商和明细归属；
3. 锁定采购申请明细；
4. 检查有效订单中的来源明细映射；
5. 校验总金额大于0且最多保留2位小数；
6. 按 `总金额 ÷ 申请数量`四舍五入到2位计算采购单价；
7. 创建采购订单、采购订单明细和单据追溯关系；
8. 使用事务校验和数据库唯一索引共同拦截重复及并发重复提交。

整单生成时，如果待生成明细在提交期间发生变化，接口返回冲突并要求刷新，避免遗漏或重复。

### 5.4 删除与重新生成

- 满足现有删除条件的采购订单删除成功后，清空订单明细的来源申请明细映射；
- 被释放的申请明细恢复为“未生成”，可以重新生成采购订单；
- 已有入库、付款或其他不满足现有删除条件的订单不能删除，也不会释放来源映射；
- 申请生成的采购订单不允许绕过采购申请页面直接修改关键明细，需要删除后重新生成。

## 六、字段与计价口径

| 业务数据       | API字段                     | 数据库字段                                                 | 规则                             |
| -------------- | --------------------------- | ---------------------------------------------------------- | -------------------------------- |
| 申请明细ID     | `applicationDetailId`       | `hspsi_purchase_approve_detail.id`                         | 前后端按字符串传输BigInt ID      |
| 订单来源明细ID | `sourceApplicationDetailId` | `hspsi_purchase_order_detail.source_application_detail_id` | 生成时写入，唯一                 |
| 申请数量       | `quantity`                  | `hspsi_purchase_approve_detail.qty`                        | 后端读取，不信任前端改写         |
| 采购总金额     | `totalAmount`               | `hspsi_purchase_order_detail.total_amout`                  | 用户输入，最终金额口径           |
| 采购单价       | `unitPrice`                 | `hspsi_purchase_order_detail.unit_price`                   | 后端按总金额除以申请数量重新计算 |
| 供应商         | `vendorId`                  | `hspsi_purchase_order.vendor_id`                           | 来源于供应商基础资料             |
| 订单总金额     | `totalAmount`               | `hspsi_purchase_order.pay_amout`                           | 按本次明细总金额精确求和         |
