# 01 快速入门

## 1. 登录系统

1. 使用浏览器打开系统地址。
2. 在“账号”中输入企业账号。
3. 在“密码”中输入账号密码。
4. 如为可信的个人电脑，可勾选“保持登录”。
5. 点击“登录”。

登录成功后进入“工作台 > 数据总览”。如果账号或密码错误，系统会在页面上显示提示。

> 公共电脑不建议勾选“保持登录”。使用结束后应点击右上角“退出登录”。

## 2. 认识主界面

### 2.1 左侧菜单

左侧为系统主菜单，当前包括：

- 工作台；
- 基础资料；
- 商品管理；
- 采购管理；
- 库存管理；
- 生产管理；
- 销售管理；
- 领用管理；
- 报表中心；
- 系统管理。

点击一级菜单展开或收起子菜单。点击左下角“收起菜单”可以缩小菜单区域。

### 2.2 顶部区域

顶部区域提供：

- 单据、商品和客户搜索入口；
- 刷新数据；
- 消息中心；
- 当前登录账号；
- 退出登录。

### 2.3 工作台

“数据总览”用于快速查看：

- 本月销售额；
- 本月采购额；
- 库存总值；
- 待审核单据；
- 采购与销售趋势；
- 库存健康度；
- 待办事项；
- 高频业务快捷入口；
- 消息中心。

工作台中的“去补货”“全部待办”“采购入库单”等按钮可直接进入对应业务页面。

## 3. 列表页通用操作

业务列表页通常由以下区域组成：

1. 页面标题和功能说明；
2. 数量、金额或状态汇总；
3. 查询条件；
4. 数据列表；
5. 分页；
6. 新增按钮和行操作按钮。

### 3.1 查询

1. 输入单号、名称或关键字。
2. 按需选择组织、仓库、状态或日期范围。
3. 点击“查询”。
4. 点击“重置”可清空条件并恢复默认列表。

查询不到数据时，请先检查组织、仓库、状态和日期范围是否过窄。

### 3.2 查看、编辑及更多操作

- “查看”：只读查看单据详情；
- “编辑”：修改当前状态允许变更的内容；
- “更多”：展开提交、审批、删除、撤销等操作；
- “新增”：创建新单据或新基础资料。

不同单据状态下可用按钮不同。例如已经确认入库的单据通常不能继续编辑。

## 4. 表单页通用操作

### 4.1 组织、部门和仓库选择顺序

建议按以下顺序填写：

1. 所属组织或公司；
2. 部门；
3. 仓库；
4. 经办人、接收人或使用人；
5. 商品和 SKU；
6. 数量、批次和金额；
7. 原因、备注等说明。

改变组织或仓库时，系统可能清空已经选择的商品明细，这是为了避免跨组织或仓库类型错误。

### 4.2 明细行

点击“添加明细”增加商品行。每行通常需要选择：

- 商品；
- SKU 或规格；
- 批次；
- 单位；
- 数量；
- 单价或成本；
- 备注。

不需要的明细可点击该行“删除”。提交前应检查是否存在空行、重复行或数量为零的行。

### 4.3 保存、提交和确认

| 操作          | 作用                             |
| ------------- | -------------------------------- |
| 保存草稿      | 暂存内容，不进入审批             |
| 保存          | 保存基础资料或当前业务记录       |
| 提交          | 进入系统现有审批流程             |
| 通过/驳回     | 审批单据；驳回时通常必须填写原因 |
| 确认入库/出库 | 立即改变真实库存                 |
| 保存并过账    | 新增通用出入库单并立即改变库存   |

## 5. 待办处理

1. 打开“工作台 > 待办事项”，或点击数据总览中的待办卡片。
2. 找到需要处理的单据。
3. 点击进入单据详情。
4. 核对组织、仓库、商品、数量、金额和申请原因。
5. 选择“通过”或“驳回”。
6. 驳回时填写清晰原因，便于申请人修改。

## 6. 安全退出

1. 点击页面右上角账号区域旁的“退出登录”。
2. 确认返回登录页。
3. 在共享电脑上关闭浏览器窗口。
