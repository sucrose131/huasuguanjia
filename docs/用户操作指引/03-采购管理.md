# 03 采购管理

## 1. 采购业务总览

常规采购流程：

```text
采购申请 → 提交审批 → 审批通过 → 采购订单 → 开始采购
→ 生成采购入库单 → 办理入库 → 库存增加
```

资金及退货流程：

```text
采购订单 → 付款
采购订单未到货部分 → 退回未到货 → 退款任务
已入库商品 → 采购退货 → 库存扣减 → 退款任务
```

## 2. 采购申请单

入口：`采购管理 > 采购申请`

### 2.1 新增申请

1. 点击“新增采购申请单”。
2. 选择所属组织、部门和目标仓库。
3. 填写申请原因、计划到货日期等信息。
4. 添加商品明细，选择商品、SKU、数量等。
5. 核对同一单据中的商品是否属于相同仓库类型。
6. 点击“保存草稿”，或点击保存并提交审批。

### 2.2 提交和审批

- 草稿状态可继续编辑、提交或删除。
- 点击“提交”后进入审批。
- 审批人员点击“通过”或“驳回”。
- 驳回时必须填写原因。
- 审批通过后系统自动形成待完善的采购订单，供应商在采购订单中补充。

## 3. 采购订单

入口：`采购管理 > 采购订单`

采购订单可以由采购申请转入，也可以点击“新增直接采购订单”创建。

### 3.1 填写订单

1. 选择组织、部门、仓库和供应商。
2. 填写到货方式、计划到货日期、配送方式、结算方式等。
3. 添加商品和 SKU，填写采购数量、单价。
4. 如创建订单时同时登记付款，付款金额不能超过订单总金额。
5. 保存订单。

### 3.2 开始采购

1. 在订单操作列选择“更多 > 开始采购”。
2. 确认供应商已经填写。
3. 核对提示并确认。

开始采购后，订单关键内容会被锁定并进入采购中状态。

### 3.3 付款

1. 找到有剩余应付金额的订单。
2. 点击“付款”。
3. 输入本次付款金额。
4. 选择付款渠道和付款日期。
5. 填写备注并确认付款。

付款金额不能超过剩余应付金额。采购付款保存后会立即更新订单累计已付和付款进度。

如付款记录录入错误，可在“采购付款”列表中按权限撤销；撤销会反向重算订单累计已付金额。

## 4. 采购入库

入口：`采购管理 > 采购入库`

### 4.1 从订单生成入库单

1. 在处于采购中或部分到货状态的订单中选择“更多 > 生成入库”。
2. 系统跳转到采购入库页面并生成待入库单。
3. 点击办理或编辑入库单。
4. 核对组织和仓库。
5. 为每条明细填写本次实收数量、批次号和入库库位。
6. 点击办理入库。

办理完成后库存立即增加。

### 4.2 入库限制

- 批次号必须填写。
- 实收数量必须大于零。
- 实收数量不能超过订单剩余可收数量。
- 仓库类型必须与商品分类一致。
- 同一采购入库单只能包含相同仓库类型的商品。

### 4.3 撤销待入库

尚未确认的待入库单可选择“撤销待入库”。已经确认并增加库存的单据不能按待入库方式撤销，应根据实际情况发起采购退货。

## 5. 采购退货

入口：`采购管理 > 采购退货`

采购退货不能直接从空白页面随意新增，必须从来源单据发起。

### 5.1 未到货退回

1. 在采购订单中选择“更多 > 退回未到货”。
2. 填写退回原因和数量。
3. 确认未到货退回。

该操作针对尚未入库的订单数量，不扣减库存。如果订单已经付款，系统会据此形成采购退款任务。

### 5.2 已入库实物退货

1. 在已确认的采购入库单中选择“更多 > 退货”。
2. 系统自动带入来源入库单、订单、供应商、仓库和批次。
3. 填写本次退货数量和退货原因。
4. 确认退货。

本次退货数量不能超过来源入库数量。操作完成后对应批次库存立即扣减，并根据已付款情况形成退款任务。

## 6. 采购退款

入口：`采购管理 > 采购退款`

退款任务只能由采购退货业务自动生成，不能手工新增。

### 6.1 确认退款

1. 找到待退款或部分退款任务。
2. 点击“确认退款”。
3. 填写退款金额、退款渠道、退款日期、供应商流水号和收款账号等信息。
4. 填写退款备注。
5. 确认退款。

支持分次退款，但累计退款不能超过剩余应退金额。

### 6.2 关闭退款任务

确实无需继续退款时，可选择“关闭退款任务”。关闭前应与财务确认，因为关闭后剩余应退金额将不再继续处理。
