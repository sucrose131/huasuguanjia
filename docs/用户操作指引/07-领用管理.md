# 07 领用管理

## 1. 领用业务流程

```text
领用申请 → 领用人签字 → 提交审批 → 审批通过
→ 自动生成领用出库草稿 → 仓库确认出库
→ 可归还物资按来源出库单办理退回
```

## 2. 领用申请

入口：`领用管理 > 领用申请单`

### 2.1 新增申请

1. 点击新增领用申请。
2. 选择所属组织、领用部门、仓库和领用人。
3. 选择领用类型。
4. 填写申请日期和申请原因。
5. 添加领用商品明细。
6. 每条明细明确选择“可归还”或“无需归还”。
7. 由领用人完成签字确认。
8. 保存草稿或提交申请。

### 2.2 提交限制

提交前必须满足：

- 组织、部门、仓库和领用人完整；
- 申请原因已填写；
- 明细商品和数量有效；
- 所选仓库内每条明细的商品规格当前库存大于 0；如填写了意向批号，则该批号当前库存也必须大于 0；
- 每行已明确是否可归还；
- 领用人已完成签字。

零库存商品仍可选择并保存为草稿，但系统会在选择时提示，且不允许提交。此处只判断是否有库存，不限制申请数量必须小于当前库存；实际可出库数量仍以仓库确认出库时的库存为准。更换领用人后，原签字会被清空，需要重新签字。

## 3. 审批领用申请

审批人员核对：

- 申请部门和领用人；
- 仓库；
- 商品、数量和用途；
- 是否可归还；
- 领用人签字。

点击“通过”或“驳回”。审批通过后系统自动生成领用出库草稿。

## 4. 领用出库

入口：`领用管理 > 领用出库单`

1. 打开审批生成的领用出库草稿。
2. 核对来源申请、领用部门、接收人和仓库。
3. 为每条商品选择实际出库批次。
4. 填写实际出库数量。
5. 保存并点击“确认”。

确认后立即扣减库存。实际出库数量不能超过申请剩余数量和批次可用库存。

## 5. 领用退回

入口：`领用管理 > 领用退回单`

退回必须基于已经确认的领用出库单，并且只允许处理标记为可归还的明细。

1. 选择来源领用出库单。
2. 系统带入来源申请、部门、经办人、仓库和可退明细。
3. 选择需要退回的商品。
4. 填写退回数量、日期和备注。
5. 保存并确认退回。

确认后对应批次库存增加。累计退回数量不能超过实际领用数量。

## 6. 注意事项

- 领用申请与领用出库是两个环节，审批通过不代表库存已经扣减。
- 仓库确认领用出库后才会真正扣减库存。
- “可归还”属性应在申请时根据实际业务判断。
- 已经标记为无需归还的明细不能通过领用退回处理。
- 当前签字保存在系统单据中；附件上传功能尚未开放。
