# 05 生产管理

## 1. 生产业务流程

```text
BOM → 销售订单 → 生产计划 → 库存分析
→ 原料出库 / 缺料处理 → 生产完成 → 成品入库
```

## 2. BOM 编排

入口：`生产管理 > BOM编排`

1. 点击新增 BOM。
2. 填写 BOM 名称。
3. 选择需要生产的成品商品和 SKU。
4. 添加原料明细，选择原料商品、SKU 和单位用量。
5. 核对每生产一件成品所需的原料数量。
6. 保存并启用 BOM。

停用的 BOM 不能用于新生产计划。修改 BOM 前应确认是否已有生产计划引用。

## 3. 生产计划

入口：`生产管理 > 生产计划单`

当前生产计划必须关联销售订单。

1. 点击新增生产计划。
2. 选择来源销售订单。
3. 选择 BOM 和生产成品。
4. 填写生产数量、计划日期和成品仓库。
5. 生产数量不能超过销售订单剩余可计划数量。
6. 保存并提交。
7. 审批人员通过或驳回。

审批通过后可进行库存分析。存在原料缺口时，系统形成缺料清单；库存充足时可以继续原料出库。

## 4. 生产缺料清单

入口：`生产管理 > 生产缺料清单`

缺料清单由生产计划库存分析生成，不能手工创建。列表显示：

- 生产计划和成品；
- 缺料商品；
- 总需求量；
- 当前库存；
- 缺口数量；
- 建议采购数量；
- 关联采购申请；
- 处理状态。

根据权限可以处理缺料、重新检查库存或终止生产计划。终止后会关闭未执行出库和未处理缺料，操作前应确认。

## 5. 生产原料出库

入口：`生产管理 > 生产出库单`

生产出库包括计划出库、临时补料和实验室领料等类型。

### 5.1 计划原料出库

1. 找到来源生产计划对应的出库单。
2. 点击“执行出库”。
3. 系统按 BOM 展示原料需求和可用批次。
4. 选择实际出库批次并填写出库数量。
5. 确认出库。

确认后立即扣减原料库存。

### 5.2 临时补料

1. 在计划出库单中发起临时补料。
2. 选择缺少的商品、SKU 和批次。
3. 填写补料数量和原因。
4. 保存后，在补料明细中点击“确认出库”。

确认补料后立即扣减库存。

### 5.3 实验室领料或临时出库

1. 点击“新增临时出库”。
2. 选择组织和仓库。
3. 至少填写一条完整的商品、SKU、批次和数量。
4. 填写原因。
5. 保存并确认。

该类出库保存后会直接执行库存扣减，应谨慎使用。

### 5.4 BOM物料退库

正式BOM整单出库确认后，可以在该出库单的更多操作中点击“BOM退库”。

1. 系统自动带出原出库仓库和每条物料当前剩余可退数量。
2. 将不需要退回的行数量改为0，部分退回时将数量改为实际退回量。
3. 按需填写退回库位；库位是自由文本，用于说明物品实际摆放位置。
4. 填写退库原因。
5. 可先保存草稿和上传附件，也可直接点击“确认退库”。

确认退库后不经过审批，库存立即增加，并且退回仓库固定为原BOM出库仓库。一张BOM出库单可以多次部分退库，但累计数量不能超过原出库数量。弹窗下方“历次退库记录”可展开查看每次退库明细和附件。

## 6. 生产成品入库

入口：`生产管理 > 生产成品入库单`

只有生产已完成且尚有未入库成品数量的计划可以办理成品入库。

1. 选择来源生产计划。
2. 核对成品、可入库数量和目标仓库。
3. 填写本次入库数量、批次、生产日期和库位。
4. 保存并确认入库。

确认后成品库存立即增加。本次入库数量不能超过生产计划剩余可入库数量。

## 7. 常见注意事项

- BOM 原料数量不准确会直接影响库存需求和缺料分析。
- 原料出库必须选择真实批次。
- 确认出库和确认成品入库都会立即影响库存。
- 发现数量错误时不要重复提交，应先确认单据是否已经过账。
- 生产计划终止前，应检查是否已经发生原料出库或成品入库。
