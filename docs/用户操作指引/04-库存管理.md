# 04 库存管理

## 1. 库存操作与库存影响

| 功能     | 是否审批 | 何时影响库存                                 |
| -------- | -------- | -------------------------------------------- |
| 库存查询 | 否       | 只读，不影响                                 |
| 通用入库 | 否       | 保存并过账后立即增加                         |
| 通用出库 | 否       | 保存并过账后立即扣减                         |
| 库存调拨 | 是       | 审批通过后按现有流程调出、调入               |
| 库存调整 | 是       | 审批通过后调整                               |
| 库存盘点 | 是       | 盘点审批只生成后续差异单，本步骤不直接改库存 |
| 报损出库 | 是       | 按处置方式在审批后扣库或转折价销售           |
| 报亏出库 | 是       | 审批通过后整单扣库                           |
| 报盈入库 | 是       | 审批通过后直接增加库存                       |

## 2. 库存查询

入口：`库存管理 > 库存查询`

1. 先选择组织。
2. 按需选择仓库、商品关键字或批次号。
3. 可勾选“仅显示有库存”。
4. 点击“查询”。

列表显示商品、SKU、仓库、批次、库存数量和库存金额。点击库存行的“流水”可查看该商品在对应仓库、批次下的入库、出库和调整记录。

### 2.1 查询领用记录与持有结存

1. 先选择组织。
2. 在库存查询顶部切换到“领用记录”。
3. 可按部门、领用人、商品/SKU、批号和领用日期组合查询。
4. “归还状态”默认选择“全部领用历史”，会同时显示可归还物品、已退清物品和无需归还的普通领用品。
5. 如只想盘点仍在人员手中的借用物品，选择“仅看持有结存”。

数量口径：`持有结存 = 已确认领用出库数量 - 已确认领用退回数量`。只有标记为可归还的明细才计入持有结存；申请中、未确认出库或未确认退回的单据不计入。

## 3. 通用入库

入口：`库存管理 > 通用入库单`

适用业务：

- 初期入库；
- 委托采购入库。

### 操作步骤

1. 点击“新增通用入库单”。
2. 选择业务类型。
3. 选择业务日期、组织和仓库。
4. 按需填写使用部门和经办人。
5. 点击“添加明细”。
6. 选择商品和 SKU，填写批次、单据数量和基础件成本。
7. 按需选择使用人并填写库位或所在位置。
8. 核对换算关系、基础件数和金额。
9. 点击“保存并过账”。

换算示例：`2箱 × 24支/箱 = 48支`。库存按 48 个基础件增加。

### 注意事项

- 通用入库不进入审批。
- 点击“保存并过账”后立即增加库存。
- 初期入库受功能开关控制；开关关闭时不能选择初期入库。
- 初期入库开关只有具备系统管理权限的人员可以修改。
- 委托采购入库不要求采购订单等上游单据。
- 同一商品、SKU 和批次不能重复填写，应合并为一行。

> 本菜单需要部署对应数据库迁移后才会显示和正常运行。

## 4. 通用出库

入口：`库存管理 > 通用出库单`

当前通用出库类型为“直接出库”。

1. 点击“新增通用出库单”。
2. 选择日期、组织和仓库。
3. 填写部门和经办人。
4. 添加明细并选择有库存的商品、SKU 和批次。
5. 填写单据数量、使用人和库位说明。
6. 核对换算后的基础件数和可用库存。
7. 点击“保存并过账”。

通用出库无需审批，保存后立即扣减库存。系统按批次移动成本计算实际出库金额。

## 5. 库存调拨

入口：`库存管理 > 库存调拨单`

1. 点击“新增库存调拨单”。
2. 选择调出组织和调出仓库。
3. 选择调入组织和调入仓库。
4. 选择发出人、接收人，填写调拨日期和原因。
5. 从调出仓库库存中选择商品、SKU 和批次。
6. 填写调拨数量。
7. 保存草稿或提交审核。
8. 审批人员核对后通过或驳回。

限制：

- 调入仓库不能与调出仓库相同。
- 调入和调出仓库类型必须匹配。
- 调拨数量不能超过当前批次库存。
- 当前仅支持普通调拨；借用调拨尚未开放。

普通调拨完成后，调入仓库可按正常库存继续处置物资。

## 6. 库存调整

入口：`库存管理 > 库存调整记录`

库存调整用于有依据地修正账面库存。

1. 从库存查询中选择库存行并发起调整，或进入库存调整页面新增。
2. 选择调整类型。
3. 填写调整数量和调整原因。
4. 确认调整后库存不小于零。
5. 保存草稿或提交审核。
6. 审批通过后完成库存调整。

库存调整必须有清晰原因，不应用来代替正常采购入库、销售出库或领用出库。

## 7. 库存盘点

入口：`库存管理 > 库存盘点`

### 7.1 创建盘点

1. 点击“新增盘点单”。
2. 选择盘点类型、组织和仓库。
3. 点击载入库存。
4. 系统载入该仓库当前库存商品和批次。
5. 逐行录入实盘数量和损坏数量。
6. 点击“保存盘点数据”可暂存。
7. 完成后点击提交审批。

损坏数量不能为负数，也不能超过实盘总数。

### 7.2 差异处理

盘点审批通过时：

- 损坏批次分别生成报损出库单；
- 盘亏数量生成报亏出库单；
- 盘盈数量生成报盈入库单；
- 盘点审批本身不直接改变库存。

后续需要在对应的报损、报亏和报盈页面继续处理。

## 8. 报损、报亏和报盈

### 8.1 报损出库

入口：`库存管理 > 报损出库单`

报损可以由盘点损坏生成，也可以日常独立新增。提交前必须选择处置方式：

- 直接报废：审批通过后扣减库存；
- 折价出售：审批通过后生成折价销售单，本步骤不立即扣减库存。

盘点自动生成的报损明细不能随意修改。

### 8.2 报亏出库

入口：`库存管理 > 报亏出库单`

报亏出库由盘点盘亏生成。审批通过后按整单全部商品、批次和盘亏数量一次性扣减库存，不支持分批出库。

### 8.3 报盈入库

入口：`库存管理 > 报盈入库单`

报盈入库由盘点盘盈生成。审批通过后直接增加对应批次库存。

## 9. 库存预警和效期预警

### 9.1 库存预警

入口：`库存管理 > 库存预警`

列表显示实际库存、安全库存、缺口和建议补货数量。管理员可编辑安全库存及建议补货数量，两项都不能小于零。

### 9.2 效期预警

入口：`库存管理 > 效期预警`

用于按商品效期配置查看临期或过期批次。可结合仓库、商品和预警类型筛选。
