## 3. 重要操作原则

- 带红色星号的字段为必填项。
- 先选择组织，再选择该组织下的部门和仓库。
- 商品分类与仓库类型必须匹配，同一业务单据通常只能包含同类仓库商品。
- 数量必须为正整数；系统不支持不足一个基础单位的出库。
- “保存草稿”不会进入审批；“提交”后才进入审批流程。
- 界面提示“确认后会立即改变真实库存”时，操作完成后会直接增减库存。
- 通用入库和通用出库不走审批，点击“保存并过账”后立即影响库存。
- 删除、撤销、作废、确认出库、确认入库等操作必须认真核对，部分操作不可恢复。
- 页面上的按钮会根据账号权限和单据状态显示；看不到按钮不一定是系统故障。
