# 06 销售管理

## 1. 销售业务流程

```text
销售订单 → 审批 → 缺口分析 / 生产计划 → 销售出库
→ 登记收款 → 售后、退货或退款
```

## 2. 销售订单

入口：`销售管理 > 销售订单`

1. 点击新增销售订单。
2. 选择所属组织、客户和订单日期。
3. 填写客户联系电话和地址等信息。
4. 添加商品和 SKU，填写数量、售价和实际金额。
5. 核对订单总金额。
6. 保存并提交。
7. 审批人员通过或驳回。

订单审批通过后，根据业务情况可以：

- 进行缺口分析；
- 直接生成销售出库；
- 登记收款；
- 登记退款；
- 发起退货；
- 登记售后。

## 3. 缺口分析和生产关联

普通销售订单审批通过后，可选择“缺口分析”。系统判断现有库存是否满足订单需求。

需要生产的商品可转入生产计划。生产计划数量不能超过销售订单剩余可计划数量。

## 4. 销售出库

入口：`销售管理 > 销售出库单`

1. 从销售订单选择“直接出库”，或进入销售出库页面选择来源订单。
2. 选择出库仓库。
3. 为商品选择实际批次。
4. 填写本次出库数量和出库日期。
5. 保存单据。
6. 点击“确认”。

确认后立即扣减库存。订单支持分批出库，但累计出库不能超过订单数量。

已经确认的销售出库单在权限和业务状态允许时可以“撤销确认”；撤销会回退库存，操作前必须确认实物尚未交付或已追回。

## 5. 销售退货

入口：`销售管理 > 销售退货单`

退货应从已经发生出库的销售订单发起。

1. 在销售订单选择“发起退货”。
2. 选择来源销售出库单和批次。
3. 填写退货数量、退货日期和退货后处理方式。
4. 保存并确认。

确认后根据处理方式完成返库。退货数量不能超过来源出库可退数量。

已确认且处理方式为返库的退货，可在符合条件时撤销确认，撤销会反向扣减返库库存。

## 6. 销售收款

入口：`销售管理 > 销售收款`

建议从销售订单选择“登记收款”进入。

1. 核对销售订单和客户。
2. 选择组织、部门、付款方式和收款日期。
3. 输入本次收款金额。
4. 确认保存。

本次收款不能超过订单未收金额。收款保存后立即生效且不能直接编辑，如确需处理应按系统允许的撤销或资金修正流程操作。

## 7. 销售退款

入口：`销售管理 > 销售退款`

1. 从已有净收款的订单选择“登记退款”。
2. 核对累计收款、累计退款和可退金额。
3. 选择退款方式、退款日期和部门。
4. 输入退款金额并填写退款原因。
5. 确认保存。

退款只处理资金，不执行商品返库。商品返库必须通过销售退货或对应售后流程完成。

## 8. 折价销售

入口：`销售管理 > 折价销售单`

折价销售可能来自报损处置，也可以按系统允许的方式创建。

- 有可信业务来源的折价销售单：选择“确认销售并出库”后，系统按来源处置单的全部商品批次一次性扣减库存，不支持分批出库。
- 确认未售出：关闭单据，不改变库存。
- 无自动来源的折价销售单：审批通过后，需要进入销售出库单选择批次并完成折价出库。

## 9. 售后记录

入口：`销售管理 > 售后记录`

1. 从已出库销售订单选择“登记售后”。
2. 选择事件类型，填写事件日期、内容和处理人。
3. 退货或换货类售后必须选择来源销售出库单和批次。
4. 填写本次处理数量。
5. 保存并办理。

售后处理规则：

- 普通售后可标记为已完成；
- 退货售后会生成并确认销售退货返库；
- 换货售后会先完成退货返库，再生成待确认的换货出库单。
