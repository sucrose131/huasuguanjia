# 十方清源自提订单同步

将十方清源云库存自提单同步到本平台销售履约体系：销售订单、客户、出库扣库、取消回库。

**不写收款、退款、售后记录。**

对应接口文档：[cloud-stock-agent-order-api.md](./cloud-stock-agent-order-api.md)  
商品映射依赖：[商品同步.md](./商品同步.md)  
普通销售订单同步（不含自提）：[订单同步.md](./订单同步.md)

> 状态：已按业务确认实施

---

## 1. 同步范围与前提

| 项 | 约定 |
| --- | --- |
| 数据接口 | `POST /open-api/v1/cloud-stock-agent-order/list`；**以 list 为唯一快照，不调 detail** |
| 订单类型 | `order_type=1` 云仓自提、`order_type=2` 价差礼包自提均同步；明细已是基础单品 |
| 跳过 | `send_status=3` 未支付运费 |
| 金额 | 销售单 `so_amount` / `fact_amount` / 明细单价全部写 **0**；不写收款、退款 |
| 归属机构 | `list.user.mall_id` → `hspsi_sys_organization_mapping` → 平台 `org_id` |
| 仓库 | `SHIFANG_QINGYUAN_GOODS_CATEGORY_ID` 分类的 `warehouse_type` + 平台 `org_id` → 启用仓 |
| 商品 | `details[].goods_id` → `hspsi_goods_source_mapping`（`source_id`=十方清源数据源 + `source_type=STANDARD` + `source_goods_id=goods_id`，`id ASC` 第一条）；`num` 即销售/出库数量；**不走转换规则** |
| 客户 | 取 `list.user`；地址取 `list.address` |
| 发货 | `send_status∈{1已发货,2已完成}` 生成出库单并确认过账扣库存；已完成视为已发货 |
| 取消 | `send_status=4` 关单；**仅当本平台已有确认出库单**才生成退货入库并过账加库存 |
| 幂等维度 | `source_id + source_order_type + source_order_id` |
| 数据库 | 不新增表、字段、字典 |

`source_order_type`：`CLOUD_STOCK_AGENT_ORDER`（与普通销售单 `SALE_ORDER` 分开，避免外部 ID 碰撞）。

### 1.1 机构映射

与普通订单相同：`user.mall_id` → `hspsi_sys_organization_mapping(source_id=十方清源 data_source.id, source_object_id=String(mall_id))` → `org_id`。

### 1.2 状态

| 十方 `send_status` | 平台 order | delivery | service | 库存 |
| --- | --- | --- | --- | --- |
| 0 待发货 | 1 | 1 | 3 | 不出库 |
| 1 已发货 | 1 | 3 | 3 | 出库扣库 |
| 2 已完成 | 2 | 3 | 3 | 出库扣库（已出则幂等） |
| 3 未支付运费 | — | — | — | **跳过不同步** |
| 4 已取消 | 3 | 保持（已出库则保持已发货） | 3 | 已出库才回库 |

头表状态只向前。出库看发货状态，不靠物流单触发；有 `express_no` 时写入销售单 `shipper`。

首次同步即为已取消且本平台从未出库：只关单，不加库存（仓库从未扣减）。

## 2. 涉及表

与普通订单同步相同的销售履约表，但不写 `hspsi_sales_order_payment`、`hspsi_sale_order_service`。

| 表 | 用途 |
| --- | --- |
| `hspsi_sys_data_source` | code=`shifang_qingyuan` |
| `hspsi_sys_organization_mapping` | mall_id → 平台机构 |
| `hspsi_goods_source_mapping` | STANDARD 映射 |
| `hspsi_basic_customer` | 客户 |
| `hspsi_sale_order` / `_detail` | 销售单（金额 0） |
| `hspsi_sale_order_output` / `_detail` | 出库 |
| `hspsi_sale_order_exit` / `_detail` | 取消回库（系统通用退货入库单） |
| `hspsi_sale_order_source_mapping` | 外部自提单幂等映射 |

## 3. 映射与幂等键

| 字段 | 说明 |
| --- | --- |
| `source_id` | 十方清源 data_source.id |
| `source_order_type` | `CLOUD_STOCK_AGENT_ORDER` |
| `source_order_id` | 十方自提单 `id` 字符串 |
| `source_order_no` | 十方 `order_no` |
| `source_status` | 最近应用的 `send_status` |
| `source_updated_at` | list `created_at`（list 无 `updated_at`） |

增量水位用映射表 `last_sync_at` 最大值减去 5 分钟重叠，作为 list 的 `start_time`（接口按源 `updated_at` 过滤）。不传 `end_time`。

| 业务 | 键 |
| --- | --- |
| 出库单据防重 | 出库单 `remark`：`SFQY-AGENT-SHIP-{sourceId}-{orderId}` |
| 出库过账 | `shifang-qingyuan-output:{so_output_id}:v1` |
| 回库单据防重 | `source_output_id` = 本平台出库单 ID，同一出库单一张退货入库 |
| 回库过账 | `sfqy-exit:{so_output_id}:v1` |

回库单据写入系统通用 `hspsi_sale_order_exit`，库存走通用 `SALES_RETURN` 过账引擎。创建由同步代码完成（已确认），不走销售页人工退货接口。

## 4. 客户与销售单头

| 平台字段 | 取值 |
| --- | --- |
| 客户幂等 | `source_type`=数据源 id，`related_customer_id`=`user.id` |
| 新建客户 | `name`=`user.nickname`→`username`→`用户{id}`；`mobile`=`user.mobile`→`username`；`address`=`list.address`；`levels=[]` |
| 已存在客户 | 只更新 `address`，不覆盖姓名 / 手机 / 推荐人 / 状态 / `levels` |
| 销售单抬头 | `customer_name/mobile` 取 user；`customer_address` 取 `list.address` |
| `so_type` | 1 实体（发货需出库） |
| `so_qty` | 明细 `num` 合计 |
| 金额 | 全 0 |
| `approve_comment` | 十方清源自提订单同步 |

找不到 STANDARD 映射或机构未映射：整单失败。

## 5. 同步主流程

```
1. 分页 list（start_time 默认映射表最大 last_sync_at 减重叠，空页退出）
2. 每单以 list 元素 apply：
   未支付运费 / 未知状态 → skip
   ensureDataSource → resolveOrg(user.mall_id) → resolveWarehouse
   → ensureCustomer(user + list.address) → resolveOrderLines(STANDARD)
   → upsert mapping(RETRY) → upsert SO（金额 0）
   → send_status∈{1,2} 则 ensureShipments（不走转换规则）
   → send_status=4 且已有确认出库则 ensureRestock（过账键绑 so_output_id）
   → mapping SUCCESS + last_payload
```

触发方式：由「系统管理 > 任务管理」调度 `shifang-qingyuan:agent-orders`；不提供 HTTP 接口，可在任务管理页立即执行。

- 批量：`ShifangQingyuanAgentOrderSyncService.syncAgentOrders(userId, options?)`
- 实现：`apps/api/src/integrations/shifang-qingyuan/sync/agent-order-sync.service.ts`
- 进程内防重入：上一轮未结束则拒绝

## 9. 遗留

- HTTP 手动同步接口不提供
- list 无 `updated_at`，增量靠 `last_sync_at` 重叠窗口；同状态变更（仅物流单号）可能跳过
- 配货单等其他云库存单据不在本项
