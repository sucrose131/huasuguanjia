# 十方清源商品同步

将十方清源商城商品同步到本平台商品体系，建立外部映射与出库转换规则。

对应接口文档：[goods-api.md](./goods-api.md)

---

## 1. 触发方式


| 项   | 说明                                                   |
| --- | ---------------------------------------------------- |
| 调度  | 「系统管理 > 任务管理」中的 `shifang-qingyuan:goods`；可立即执行 |
| 调用  | `ShifangQingyuanGoodsSyncService.syncGoods(userId)`  |
| 范围  | 全量同步（分页拉取十方清源全部商品后落库）                                |
| 幂等  | 以 `hspsi_goods_source_mapping` 定位已有平台商品；存在则更新，不存在则创建 |
| 防重入 | 进程内 `running`；上一轮未结束则拒绝 |


实现位置：

- `apps/api/src/integrations/shifang-qingyuan/sync/goods-sync.service.ts`
- 常量：`apps/api/src/integrations/shifang-qingyuan/shifang-qingyuan.constants.ts`
- 类型：`apps/api/src/integrations/shifang-qingyuan/shifang-qingyuan.types.ts`
- API 封装：`apps/api/src/integrations/shifang-qingyuan/shifang-qingyuan.service.ts`

## 3. 源数据含义（十方清源）

十方清源 `POST /open-api/v1/goods/list` 返回商品列表，每个商品包含以下子结构：

### 3.1 `goods`（商品主信息）

- 商品 SPU 基础信息：名称、售价（元）、封面图、单位、上架状态等
- `is_on_sale=1 且 status=1` 为上架；否则为下架

### 3.2 `qimall_goods_attr`（SKU 规格列表）

- 每个商品含多个 SKU
- **默认规格**：`sort` 最小的 SKU；若都一样取第一个
- 每个 SKU 有独立的售价（元）、库存、图片

### 3.3 `cloud_stock_gift_plan`（云库存赠送方案）

- `give_goods_num` 为**对象格式**：`{ "商品id": 数量 }`
- 表示购买该商品时，赠送对应商品及数量
- `status=1` 为启用
- 接口空值可能是 `[]` 或 `{}`（PHP 空数组），同步时统一按空数组

### 3.4 `cloud_stock_upgrade_bag`（云库存升级礼包）

- `give_goods_num` 为**数组格式**：`[{ goods_id, num }]`
- 表示购买该商品时，按升级礼包出库对应商品及数量
- `status=1 且 is_enable=1` 为启用
- 接口空值可能是 `[]` 或 `{}`；单条也可能是对象而不是数组。同步时统一规范成数组

### 3.5 出库方式判定


| 条件                                | source_type | 出库方式    |
| --------------------------------- | ----------- | ------- |
| `gift_plan` 和 `upgrade_bag` 均为空   | `STANDARD`  | 自身出库    |
| `gift_plan` 有值 或 `upgrade_bag` 有值 | `MAPPED`    | 按转换规则出库 |

## 4. 同步流程

```
1. 分页拉取全部商品（limit=100；空页或不足一页则结束，避免 total 偏大死循环）
2. 确保数据源 shifang_qingyuan；加载平台单位表
3. 第一轮：同步所有商品 SPU + SKU + source_mapping
   - 上架/下架均写 mapping_status=MAPPED（源端下架不停用映射）
4. 第二轮：处理 gift_plan 和 upgrade_bag 的转换规则
   - 依赖第一轮已同步的商品映射
   - 方案清空/全停用：停用该商品全部旧转换规则
   - 目标变更：自动停用已移除的旧转换规则
5. 第三轮：本次未成功同步的源商品（列表缺失 / 无 SKU 跳过等）
   - 仅写 warnings 告警
   - **不**停用 mapping / conversion_rule，**不**下架平台商品
```

### 4.1 下架商品处理

源端 `is_on_sale=0` 或 `status!=1`：

- **仍创建/更新** SPU + SKU + source_mapping
- 平台商品保持 `status=1`（源端下架不连带下架平台商品）
- `mapping_status=MAPPED`（订单同步仍可按规格解析）
- 统计上归入 `goods.mappingOnly`

### 4.2 无 SKU 商品处理

跳过，不计入创建/更新

- 记入 `warnings`
- 若历史上已有 mapping：第三轮仅告警，不删改平台数据

### 4.3 源端删除/不再返回的商品

全量同步收尾时，对「本轮未写入 `syncedGoods`」的已有 mapping：

- **保留** mapping、conversion_rule、平台商品（历史订单依赖）
- 写 `warnings` 提示源端未返回数量

## 5. 字段与落库规则

### 5.1 公共默认值


| 字段               | 取值                                                      |
| ---------------- | ------------------------------------------------------- |
| `org_id`         | `0`                                                     |
| `warehouse_id`   | `0`                                                     |
| `vendor_id`      | `0`                                                     |
| `supply_type`    | `1`（自产）                                                 |
| `goods_catg_id`  | 常量 `SHIFANG_QINGYUAN_GOODS_CATEGORY_ID`（默认 `1`，按环境修改）   |
| `unit_type`      | 用十方清源 `goods.unit` 匹配 `hspsi_basic_unit.name`；匹配不到为 `0` |
| 售价               | 十方清源 `price`（元）直接落库                                     |
| `mapping_status` | 同步成功一律 `1=已映射`（源端下架/消失不停用）                            |
| `source_type`    | `STANDARD` / `MAPPED`                                   |
| 数据源 code         | `shifang_qingyuan`                                      |


### 5.2 商品 SPU（`hspsi_goods_info`）


| 十方清源字段             | 平台字段                             | 转换规则                                        |
| ------------------ | -------------------------------- | ------------------------------------------- |
| `goods.id`         | `source_mapping.source_goods_id` | String(id)                                  |
| `goods.goods_name` | `goods_name`                     | clip(100)                                   |
| `goods.cover_pic`  | `goods_image`                    | clip(255)，默认空串                              |
| `goods.subtitle`   | `spec_models`                    | 默认规格的 `spec_models`（与 SKU 表一致），不使用 subtitle |
| `goods.unit`       | `unit_type`                      | 匹配 `hspsi_basic_unit.name`                  |
| `goods.price`      | `sale_price`                     | 元 → Decimal(10,2)，不做 ÷100                  |
| `goods.is_on_sale` | `status`                         | 不同步下架；平台始终保持可用（`1`）                         |
| `goods.sort`       | `sort`                           | 直接映射                                        |
| `goods.goods_type` | `goods_type`                     | 1→1(实物), 2→2(虚拟)                            |
| `goods.subtitle`   | `remark`                         | clip(255)                                   |
| -                  | `goods_catg_id`                  | 固定常量 `1`                                    |
| -                  | `query_code`                     | 由 `goods_name` 生成拼音首字母                      |


### 5.3 SKU（`hspsi_goods_info_sku`）


| 十方清源字段            | 平台字段                           | 转换规则                     |
| ----------------- | ------------------------------ | ------------------------ |
| `attr.id`         | `source_mapping.source_sku_id` | String(id)               |
| `attr.name`       | `spec_models`                  | clip(200)，空或仅空白则用「默认规格」 |
| `attr.price`      | `sale_price`                   | 元 → Decimal(10,2)，不做 ÷100 |
| `attr.cost_price` | `const_price`                  | 元 → Decimal(10,2)，不做 ÷100 |
| `attr.pic_url`    | `image`                        | clip(255)                |
| `attr.stock`      | `pcs_qty`                      | **不同步**，固定为 `1`，平台自行管理库存 |
| `attr.sort`       | `sort`                         | 直接映射                     |
| `attr.status`     | `status`                       | 1→1, 0→0                 |
| 默认规格              | `is_default`                   | sort 最小的为 1，其余 0         |


每个 SKU 独立写一条 `source_mapping`（`source_sku_id` = 真实 attr.id）。

### 5.4 转换规则（`hspsi_goods_sku_conversion_rule`）

来源为 `gift_plan` 和 `upgrade_bag`，按目标数量决定 `rule_type`（与华溯约定一致）：

| 有效目标数 | `rule_type` | 含义 |
| --- | --- | --- |
| 1 | `1` REPLACE | 一对一替换 |
| ≥2 | `2` COMBO_SPLIT | 组合拆解 |

| 来源            | give_goods_num 格式        | 解析方式   |
| ------------- | ------------------------ | ------ |
| `gift_plan`   | 对象 `{ "商品id": 数量 }`      | 遍历键值对  |
| `upgrade_bag` | 数组 `[{ goods_id, num }]` | 遍历数组元素 |


每条转换规则：

- `source_goods_id` / `source_sku_id` = 当前商品的默认 SKU
- `target_goods_id` / `target_sku_id` = give_goods_num 中目标商品的默认 SKU
- `quantity_ratio` = 数量值（至少为 1）
- `rule_type` = 按本轮成功解析的目标数：1 个用 REPLACE，多个用 COMBO_SPLIT
- `status` = `1`（启用）

转换规则变更（数量变 / 换目标商品 / 删除某项 / 方案整体清空）：

- 数量、目标：再次同步会更新
- 已不在 give_goods_num 中的旧规则：同步时**停用并软删**
- gift_plan / upgrade_bag 全部清空或停用：该商品**全部**旧规则停用并软删
- 源端商品不再返回：第三轮停用 mapping，并停用以其为 source 的转换规则

## 6. 映射表约定（`hspsi_goods_source_mapping`）


| 字段                    | 说明                                                  |
| --------------------- | --------------------------------------------------- |
| `source_id`           | `hspsi_sys_data_source.id`（code=`shifang_qingyuan`） |
| `source_type`         | `STANDARD` / `MAPPED`                               |
| `source_goods_id`     | 十方清源商品 id 字符串                                       |
| `source_sku_id`       | 十方清源 SKU id 字符串（真实 `qimall_goods_attr.id`）          |
| `goods_id` / `sku_id` | 平台内部商品/规格                                           |
| `mapping_status`      | `1=已映射`，`2=待确认`，`3=已停用`                             |


每个 SKU 写一条映射（`source_sku_id` = 真实 attr.id）。不再写 `source_sku_id="0"` 的商品级默认映射；再次同步时会停用并软删历史冗余的 `"0"` 映射。

查找已有映射时**不区分 source_type**，兼容 `STANDARD ↔ MAPPED` 变更。

---

## 7. 转换规则约定（`hspsi_goods_sku_conversion_rule`）


| `rule_type` | 含义 | 场景 |
| ----------- | --- | ---------------------------------------- |
| `1` | 一对一替换 | give_goods_num 仅 1 个目标 |
| `2` | 组合拆解 | give_goods_num 有多个目标 |



| `status` | 含义  |
| -------- | --- |
| `1`      | 启用  |
| `2`      | 停用  |


唯一键：`(source_goods_id, source_sku_id, target_goods_id, target_sku_id)`

## 8. 环境与前置条件

`.env`：

```env
SHIFANG_QINGYUAN_BASE_URL="https://xxx"
SHIFANG_QINGYUAN_MALL_SIGN=""
SHIFANG_QINGYUAN_HOST=""
```


| 环境变量                         | 说明                                      |
| ---------------------------- | --------------------------------------- |
| `SHIFANG_QINGYUAN_BASE_URL`  | 十方清源 API 基础地址                           |
| `SHIFANG_QINGYUAN_MALL_SIGN` | 商城签名，对应 `qimall_mall` 表的 `mall_sign` 字段 |
| `SHIFANG_QINGYUAN_HOST`      | Host 请求头，如 `api.ten.com`                |


注意：

1. 修改 `SHIFANG_QINGYUAN_GOODS_CATEGORY_ID` 为实际叶级分类 id
2. 平台单位表建议存在名称为「瓶」「盒」等十方清源常用单位
3. `BASE_URL` 尾部斜杠会自动去除
