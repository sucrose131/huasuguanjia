# 薪福通企业应用开发中心

> 官方原文见下方。华溯管家统一事件接收地址：
>
> `POST /api/integrations/xinfutong-oa/events`
>
> - 保存该地址时，薪福通会先推送连接测试事件 `XFT00000`（无签名），本系统立即返回 `{ "rtnCod": "200", "errMsg": "" }`。
> - 正式事件按本文对 `eventId`、`prjCod`、`eventTime`、`eventCd` 做 SM2 验签，并用该应用公钥前 32 位 hex 对 `eventRcdInf` 做 SM4 解密。
> - 验签公钥按应用保存在 `hspsi_sys_account_set.event_public_key`，用事件报文中的 `appId` 匹配 `app_id`。
> - 当前已处理：`XFTOAFPS`（OA 审批流程结束）。旧路径 `/api/integrations/xinfutong-oa/events/XFTOAFPS` 仍兼容。

**事件订阅可以让您的应用及时响应薪福通里的操作，从而进行高度整合。**

您需要的只是告诉薪福通该向哪里（URL）发送事件以及您关心哪些类型的事件，当事件发生时，薪福通开放平台以HTTP POST请求的方式将事件内容以JSON格式推送给您配置的地址。

## 使用场景

您的应用对数据的实时性要求比较高，希望能够及时地从薪福通同步数据的变化。比如用户离职时，应用需要第一时间处理代发付款完成的业务数据。就可以订阅代发付款完成事件等

## 事件订阅流程

一个完整的事件订阅分为两个部分：**配置请求网址以及事件订阅**和**接收并响应事件**。配置请求网址的说明请参照：[域名白名单](https://xft.cmbchina.com/open/#/doc/open-document?id=10693&mid=12767)

-   事件订阅指开发者订阅所需的事件，只有订阅后才能收到触发的事件响应。
-   请求URL用于接收订阅的事件响应  
    流程详情如下所示：  
    1.开发者设置事件回调的请求地址  
    2.保存网址时，薪福通开放平台会向应用服务器发送请求，验证网址的联通性  
    3.应用服务器收到请求，返回成功报文体，在规定的时间内响应给薪福通服务器  
    4.薪福通服务器响应给开发者请求网址配置成功  
    5.在开发者后台应用中，在事件订阅菜单中订阅需要的事件  
    6.事件触发后，薪福通服务器感知到事件，发送事件内容给应用服务器  
    7.应用服务器收到事件内容后，在规定的时间内做出响应返回给薪福通服务器。

### 接收并响应事件

订阅的事件发生时，薪福通将会通过HTTP POST请求发送Json格式的事件数据到设置的推送接收地址中。

**推送内容**

| 参数名 | 数据类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| eventId | string | 是 | 事件id |
| eventRcdInf | string | 是 | 事件变更信息（json串） |
| prjCod | string | 否 | 企业号 （平台类事件没有企业号） |
| eventTime | string | 是 | 变更时间 |
| eventCd | long | 是 | 事件唯一记录码 |
| businessKey | string | 是 | 事件业务码 |
| appId | string | 是 | 应用id |
| signature | string | 是 | 签名字段 |```
{  
    "eventId": "XXXX",  
    "eventRcdInf": "xxxx",  
    "prjCod": "XXXXX",  
    "eventTime": "2021-08-27T12:00:00.534(2021-08-27T12:00:00 这两种格式都有可能)",  
    "eventCd": 9999,  
    "businessKey": "XXX",  
    "appId": "XXX",  
    "signature": "XXX"  
}  
```

**收到请求后，需要3S内以Http 200状态码响应该请求，否则薪福通开放平台会认为此次推送失败，最多重试3次，接收方可以根据appId和businessKey做唯一性，进行等幂操作。**

#### URL验证是否成功，返回的报文体格式

```
{  
  "rtnCod":"200",  
  "errMsg":""  
}  
```

#### 事件验签和解密

```
import com.alibaba.fastjson.JSONObject;  
import org.bouncycastle.asn1.ASN1EncodableVector;  
import org.bouncycastle.asn1.ASN1Integer;  
import org.bouncycastle.asn1.DERSequence;  
import org.bouncycastle.crypto.params.ECDomainParameters;  
import org.bouncycastle.crypto.params.ECPublicKeyParameters;  
import org.bouncycastle.crypto.params.ParametersWithID;  
import org.bouncycastle.crypto.signers.SM2Signer;  
import org.bouncycastle.jce.ECNamedCurveTable;  
import org.bouncycastle.jce.spec.ECParameterSpec;  
import org.bouncycastle.math.ec.ECPoint;  
import org.bouncycastle.util.encoders.Hex;  
import org.springframework.util.Assert;  
import org.springframework.util.StringUtils;

import java.io.IOException;  
import java.math.BigInteger;  
import java.util.HashMap;  
import java.util.Map;  
import java.util.TreeMap;

  
public class SM2VerifyUtils {

    private static final String SIGNATURE = "signature";

      
    public static boolean verify(String publicKeyStr, String msgStr, String signatureStr) throws Exception {


        byte[] pubkey = Hex.decode(publicKeyStr);  
        byte[] msg = msgStr.getBytes();  
        byte[] signature = Hex.decode(signatureStr);  
        if (signature.length != 64) {  
            throw new RuntimeException(signatureStr + "签名格式不对");  
        }  
        return verify(pubkey, msg, signature);  
    }

      
    public static String verifyAndProcess(String publicKeyStr, String msgStr) {  
        Assert.isTrue(!StringUtils.isEmpty(publicKeyStr), "解签公钥不能为空");  
        Assert.isTrue(!StringUtils.isEmpty(msgStr), "密文不能为空");

        Map<String, Object> msgData = JSONObject.parseObject(msgStr, HashMap.class);  
        Assert.notNull(msgData.get(SIGNATURE), "消息签名为空，请确认参数是否经过加签！");  
        Assert.isTrue(verify(publicKeyStr, msgStr), "签名验证失败！");  
        msgData.remove(SIGNATURE);  
        return JSONObject.toJSONString(msgData);  
    }

      
    public static boolean verify(String publicKeyStr, String msgStr) {  
        try {  
            Assert.isTrue(!StringUtils.isEmpty(publicKeyStr), "解签公钥不能为空");  
            Assert.isTrue(!StringUtils.isEmpty(msgStr), "接口参数不能为空");  
            Map<String, Object> msgData = JSONObject.parseObject(msgStr, HashMap.class);  
            Assert.notNull(msgData.get(SIGNATURE), "消息签名为空，请确认参数是否经过加签！");  
            String signatureStr = String.valueOf(msgData.remove(SIGNATURE));  
            String param = JSONObject.toJSONString(new TreeMap<>(msgData));  
            if (publicKeyStr.length() != 130) {  
                return false;  
            }  
            byte[] pubkey = Hex.decode(publicKeyStr);  
            byte[] msg = param.getBytes();  
            byte[] signature = Hex.decode(signatureStr);  
            return verify(pubkey, msg, signature);  
        } catch (Exception e) {  
            return false;  
        }  
    }

    private static boolean verify(byte[] pubkey, byte[] msg, byte[] signature) throws IOException {  
        if (signature.length != 64) {  
            return false;  
        }  
        ECPublicKeyParameters publicKey = encodePublicKey(pubkey);  
        SM2Signer signer = new SM2Signer();  
        ParametersWithID parameters = new ParametersWithID(publicKey, "1234567812345678".getBytes());  
        signer.init(false, parameters);  
        signer.update(msg, 0, msg.length);  
        return signer.verifySignature(encodeDERSignature(signature));  
    }

    private static byte[] encodeDERSignature(byte[] signature) throws IOException {  
        byte[] r = new byte[32];  
        byte[] s = new byte[32];  
        System.arraycopy(signature, 0, r, 0, 32);  
        System.arraycopy(signature, 32, s, 0, 32);  
        ASN1EncodableVector vector = new ASN1EncodableVector();  
        vector.add(new ASN1Integer(new BigInteger(1, r)));  
        vector.add(new ASN1Integer(new BigInteger(1, s)));

        return (new DERSequence(vector)).getEncoded();  
    }

    private static ECPublicKeyParameters encodePublicKey(byte[] value) {  
        byte[] x = new byte[32];  
        byte[] y = new byte[32];  
        System.arraycopy(value, 1, x, 0, 32);  
        System.arraycopy(value, 33, y, 0, 32);  
        BigInteger xValue = new BigInteger(1, x);  
        BigInteger yValue = new BigInteger(1, y);  
        ECPoint qValue = ECNamedCurveTable.getParameterSpec("sm2p256v1").getCurve().createPoint(xValue, yValue);  
        return new ECPublicKeyParameters(qValue, getECDomainParameters());  
    }

    private static ECDomainParameters getECDomainParameters() {  
        ECParameterSpec spec = ECNamedCurveTable.getParameterSpec("sm2p256v1");  
        return new ECDomainParameters(spec.getCurve(), spec.getG(), spec.getN(), spec.getH(), spec.getSeed());  
    }  
}

##### 第二步：引入SM4加解密工具类

```

import org.bouncycastle.jce.provider.BouncyCastleProvider;  
import org.bouncycastle.pqc.math.linearalgebra.ByteUtils;

import javax.crypto.Cipher;  
import javax.crypto.spec.SecretKeySpec;  
import java.nio.charset.StandardCharsets;  
import java.security.Key;  
import java.security.Security;

public class Sm4Util {  
    static {  
        Security.addProvider(new BouncyCastleProvider());  
    }  
    public static final String ALGORITHM_NAME = "SM4";  
    
    
    
    public static final String ALGORITHM_NAME_ECB_PADDING = "SM4/ECB/PKCS5Padding";

      
    private static Cipher generateEcbCipher(String algorithmName, int mode, byte[] key) throws Exception {  
        Cipher cipher = Cipher.getInstance(algorithmName, BouncyCastleProvider.PROVIDER_NAME);  
        Key sm4Key = new SecretKeySpec(key, ALGORITHM_NAME);  
        cipher.init(mode, sm4Key);  
        return cipher;  
    }

      
    public static String encryptEcb(String hexKey, String paramStr) throws Exception {  
        byte[] keyData = ByteUtils.fromHexString(hexKey);  
        byte[] srcData = paramStr.getBytes(StandardCharsets.UTF_8);  
        byte[] cipherArray = encryptEcbPadding(keyData, srcData);  
        return ByteUtils.toHexString(cipherArray);

    }

    public static byte[] encryptEcbPadding(byte[] key, byte[] data) throws Exception {  
        Cipher cipher = generateEcbCipher(ALGORITHM_NAME_ECB_PADDING, Cipher.ENCRYPT_MODE, key);  
        return cipher.doFinal(data);  
    }

      
    public static String decryptEcb(String hexKey, String cipherText) throws Exception {  
        byte[] keyData = ByteUtils.fromHexString(hexKey);  
        byte[] cipherData = ByteUtils.fromHexString(cipherText);  
        
        byte[] srcData = decryptEcbPadding(keyData, cipherData);  
        return new String(srcData, StandardCharsets.UTF_8);

    }

    public static byte[] decryptEcbPadding(byte[] key, byte[] cipherText) throws Exception {  
        Cipher cipher = generateEcbCipher(ALGORITHM_NAME_ECB_PADDING, Cipher.DECRYPT_MODE, key);  
        return cipher.doFinal(cipherText);  
    }  
}  
```
