# OA审批表单字段设计

> 用途：交由 OA 配置人员创建审批表单。
>
> 设计原则：表单只展示审批判断所需内容；本地主键、明细 ID、商品 ID、SKU ID、`busKey`、`procInstId` 等技术字段不作为 OA 控件。

## 一、先完成 OA 表单配置

需要 OA 侧创建以下 11 张审批表单。表单控件创建并发布后，请回传每张表单的 `formKey`、`formId` 及各控件 `uniqueName`。

## 二、OA 配置完成后需返回的信息

每张表单创建发布后，请 OA 配置人员返回：

| 返回内容                        | 用途               |
| ------------------------------- | ------------------ |
| 表单名称                        | 核对业务表单       |
| `formKey`                       | 发起流程时指定表单 |
| `formId`                        | 标识当前发布版本   |
| 每个控件的 `uniqueName`         | 组装 OA `formData` |
| 表格及表格子控件的 `uniqueName` | 组装明细数组       |
| 附件控件的 `uniqueName`         | 传递 OA 文件数组   |

OA 返回上述信息后，再进行华溯管家字段映射和接口开发。
