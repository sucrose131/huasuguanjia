# 外部系统调用华溯之家系统
## 接口方式
* 请求方式：post
* 内容类型：application/json
* 请求头（编码后的签名）：X-Sign
* 请求头时间戳（秒）：X-Timestamp
* 请求头时间戳（秒）：X-Nonce
* 


## 请求头

| 参数名 | 类型 | 是否必传 |描述 |
| --- | --- | --- |--- |
| X-Sign | string | 是 |签名 |
| X-Timestamp | string | 是 |当前时间戳（秒） |
| X-Nonce | string | 是 |随机串（32位） |

## 签名生成
* 1. 请求参数 Key 按 ASCII 升序排序
* 2. 排序后参数进行json_encode 256，json编码后的字符串在前面拼接时间戳，后面拼接随机串组成待签名字符串。
* 3. 使用公钥进行对待签名串进行加密生成签名（OPENSSL_PKCS1_PADDING）
* 4. 对签名进行base64_encode编码
> 备注：
> 1. 公钥和私钥接收方生成，提供公钥给调用方；
