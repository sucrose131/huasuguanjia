
## POST 会议订单

POST /hspsi/order-conference/list

> Body 请求参数

```json
{
    "page": 1,
    "page_size": 100,
    "updated_at": "2026-05-30 00:00:00"
}
```

### 请求参数

|名称|位置|类型|必选|中文名|说明|
|---|---|---|---|---|---|

|body|body|object| 是 ||none|
|» page|body|integer| 是 | 页码|none|
|» page_size|body|integer| 是 | 每页数量|默认100条，最大1000条|
|» updated_at|body|string| 是 | 更新时间|格式：Y-m-d H:i:s|

|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|Inline|
