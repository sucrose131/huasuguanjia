# 华溯之家用户同步

将华溯之家用户列表同步到本平台客户主数据，并在 `levels` JSON 中保存身份描述：百岁加会员、省级合伙人、推广身份。

对应接口文档：[用户列表.md](./用户列表.md)  
请求签名规则：[请求规则.md](./请求规则.md)  
与订单侧客户对齐：[订单同步.md](./订单同步.md)（同一幂等键；**订单同步也会全量 upsert 客户含 `levels`**）

> 状态：已按业务确认实施

---

## 1. 需求与边界

| 项 | 约定 |
| --- | --- |
| 触发方式 | 由「系统管理 > 任务管理」中的 `huasu-home:users` 按 Cron 调度；本期**不提供**手动 HTTP 触发接口，可在任务管理页立即执行 |
| 落库目标 | `hspsi_basic_customer` |
| 幂等键 | `source_type = 数据源 id` + `related_customer_id = 华溯 user.id` |
| 身份存储 | 单字段 `levels`（JSON），只存三类身份的**描述信息**，**不存**华溯等级主键等 ID |
| 机构未映射 | **单条失败**：该用户记失败并跳过，其余用户继续写入 |
| 来源机构 ID | 华溯 `organization_id` **不要求大于 0**：`0`、`1` 只要已在 `hspsi_sys_organization_mapping` 映射即可写入 |
| 订单同步 | **同步 upsert 客户**（不存在创建、存在全量更新，含 `levels`）；用户同步服务仍负责无订单用户补齐 |
| 暂缓 | 余额/佣金/积分/黑名单等；手动同步接口；按手机号合并 |

## 3. `levels` JSON 结构

只存中文标签数组，不存华溯 `level_id` / `uid` / 等级数值等。

```json
["全家福会员", "省级合伙人", "百岁加会员-主卡"]
```

写入规则（仅写入已具备的身份，顺序固定）：

| 顺序 | 条件 | 写入文案 |
| --- | --- | --- |
| 1 | `level.name` 非空 | 推广身份名称，如 `全家福会员` |
| 2 | `is_provincial_partner=1` | `省级合伙人` |
| 3 | `is_centenarian=1` | `百岁加会员-主卡/副卡/次卡`（按 `centenarian_type` 1/2/3）；类型未知时写 `百岁加会员` |

无任何身份时存 `[]`。

`centenarian_type`：`1-主卡，2-副卡，3-次卡`。

## 5. 同步流程

增量拉取：请求体必传 `id`（最小用户 ID），接口返回 **id 大于该值** 的用户。

```
1. 校验数据源 id 可落入 source_type
2. 取水位 afterUserId：
   - 默认同数据源客户 max(related_customer_id)（无记录则为 0）
   - 可入参覆盖（回拨水位做补齐/重试）
3. 循环 POST /hspsi/user/list：page 固定 1，page_size 固定，id=afterUserId；按页即时处理
4. 本页处理完后 afterUserId = 本页 max(user.id)，继续拉下一截，直到空页或不足一页
5. 页内并发写入：按 source_type + related_customer_id 查找后创建或更新；机构问题单条失败（不再拦截 organization_id < 1）
6. 输出统计：fetched / created / updated / failed / afterUserId / lastUserId
```

说明：水位按「本页最大 user.id」前进；机构未映射等单条失败不会挡住后续新用户，但失败用户需回拨 `afterUserId`（或修映射后全量重拉）才会再被拉到。

无分布式锁；进程内 `running` 防重入，上一轮未结束则跳过本轮。

触发方式由「系统管理 > 任务管理」调度 `HuasuHomeUserSyncService.syncUsers()`，开关和 Cron 存在 `hspsi_sys_scheduled_task`。进程内 `running` 防重入，上一轮未结束则跳过本轮。

分页配置：

| 项 | 本期 | 说明 |
| --- | --- | --- |
| 分页 | 代码常量 | `page_size=200`；**不走环境变量** |
| 调度 | 数据库配置 | 开关、Cron 由任务管理表维护；分页仍为代码常量 |

实现位置：

- `apps/api/src/integrations/huasu-home/sync/user-sync.service.ts`
