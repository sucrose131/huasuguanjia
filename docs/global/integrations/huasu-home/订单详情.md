## POST 订单信息

POST /hspsi/order/info

> Body 请求参数

```json
{
    "order_sn": "OR2608080100000444212"
}
```

|名称|位置|类型|必选|中文名|说明|

|body|body|object| 是 ||none|
|» order_sn|body|string| 是 | 订单编号|none|
