# 华溯之家商品同步

将华溯之家商品列表同步到本平台商品体系，建立外部映射与发货转换规则。

对应接口文档：[商品列表.md](./商品列表.md)  
请求签名规则：[请求规则.md](./请求规则.md)

---

## 1. 触发方式

| 项 | 说明 |
| --- | --- |
| 接口 | `POST /integrations/huasu-home/sync/products` |
| 权限 | 登录 + `goods` |
| 范围 | 全量同步（拉取华溯全部 `products` + `packages` 后落库） |
| 幂等 | 以 `hspsi_goods_source_mapping` 定位已有平台商品；存在则更新，不存在则创建 |

实现位置：

- `apps/api/src/integrations/huasu-home/sync/product-sync.service.ts`
- `apps/api/src/integrations/huasu-home/huasu-home.controller.ts`
- 常量：`apps/api/src/integrations/huasu-home/huasu-home.constants.ts`

---

## 2. 涉及表

| 表 | 用途 |
| --- | --- |
| `hspsi_goods_info` | 平台商品（SPU） |
| `hspsi_goods_info_sku` | 平台规格（SKU） |
| `hspsi_goods_source_mapping` | 华溯商品/规格 ↔ 平台商品/规格 |
| `hspsi_goods_sku_conversion_rule` | 下单规格 → 真实发货规格（一对一替换 / 套餐拆解） |
| `hspsi_sys_data_source` | 数据来源；code=`huashu_home`，不存在时同步过程自动创建 |

---

## 3. 源数据含义（华溯）

华溯 `POST /hspsi/product/list` 返回两类数据：

### 3.1 `products`（单品）

- 每个单品含 `skus[]`
- **默认规格**：`skus` 中 `number === 1` 的规格；若有多个，取列表中**第一个**
- 若存在 `mapping`：表示下单该单品时，需转换成 `mapping` 指向的真实发货商品（`mapping` 目标也会出现在 `products` 中）

### 3.2 `packages`（套餐）

- 套餐本身在平台建 1 个商品 + 1 个 SKU
- `singles[]` 为套餐组成；发货按其中的 `product_id` 对应单品的**默认规格**拆解
- `singles.id` **不可信、忽略**；映射表中套餐的 `source_sku_id` 固定为 `"0"`
- 套餐规格名称：直接用 `singles[].name` 拼接，**不**再按 `product_id` 反查单品名
- 当前约定：`singles` **不会**指向带 `mapping` 的单品

---

## 4. 同步流程

```
1. 拉取商品列表（products + packages）
2. 确保数据源 huashu_home；加载平台单位表
3. 先同步全部单品 → 写入 goods / sku / source_mapping(STANDARD)
4. 处理带 mapping 的单品 → 写入 conversion_rule(rule_type=1)
5. 同步套餐 → 写入 goods / 唯一 sku / source_mapping(COMBO)
6. 写入套餐拆解 conversion_rule(rule_type=2)，并清理已移除的旧拆解规则
```

源端 `status=0` 或存在有效 `deleted_at`：

- **仅**将对应 `source_mapping.mapping_status` 置为 `3=已停用`
- **不**修改平台商品主数据

---

## 5. 字段与落库规则

### 5.1 公共默认值

| 字段 | 取值 |
| --- | --- |
| `org_id` | `0` |
| `warehouse_id` | `0` |
| `vendor_id` | `0` |
| `supply_type` | `1`（自产） |
| `goods_catg_id` | 常量 `HUASU_HOME_GOODS_CATEGORY_ID`（按环境修改） |
| `unit_type` | 用华溯 `unit_str` 匹配 `hspsi_basic_unit.name`；匹配不到为 `0` |
| 售价 | 同步 `discount_price` |
| 库存 | **不同步** |
| `mapping_status` | 同步成功后直接 `1=已映射` |
| `source_type` | 单品=`STANDARD`，套餐=`COMBO`（本期不用 `VIRTUAL`） |
| 数据源 code | `huashu_home` |

### 5.2 单品（STANDARD）

| 华溯 | 平台 |
| --- | --- |
| `products[].id` | `source_goods_id`；`query_code` 由 `products[].name` 生成（名称拼音首字母，见下方规则） |
| `products[].skus[].id` | `source_sku_id` |
| `products[].name` / `cover` / `desc` | 商品名称 / 图片 / 备注 |
| `products[].type` | `0→goods_type=1`（实体），`1→goods_type=2`（虚拟） |
| 默认 sku 的 `name` | 写入商品表 `spec_models`，并作为该 sku 规格名；空或仅空白则写「默认规格」 |
| `skus[].number` | `pcs_qty`；转换比例也用该值 |
| 每个 sku | 一条 `source_mapping`；`goods_id` 相同、`sku_id` 不同 |
| 仅默认规格 | `is_default=1`（多个 `number=1` 时只标第一个） |

`query_code` 生成规则（单品与套餐相同）：

- 汉字 → 拼音首字母（大写；多音字取默认读音）
- 英文字母 → 转大写保留；数字保留；空格与标点等跳过
- 最长 30 字符；无法提取时写空字符串
- 允许重复；再次同步若名称变化会覆盖更新

### 5.3 带 mapping 的单品

下单品 B（有 `mapping`）→ 真实品 A：

- A、B 都同步为平台商品
- 对 **B 的每个 sku** 写一条转换规则：
  - `source` = B 的该 sku
  - `target` = A 的默认规格
  - `quantity_ratio` = **B 自身 sku 的 `number`**
  - `rule_type` = `1`（一对一替换）

### 5.4 套餐（COMBO）

| 华溯 | 平台 |
| --- | --- |
| `packages[].id` | `source_goods_id`；`query_code` 由 `packages[].name` 生成（名称拼音首字母，见下方规则） |
| `source_sku_id` | 固定 `"0"` |
| 套餐商品 | 1 个 SPU + 1 个 SKU |
| `unit_type` | 平台单位名「套」对应的 id；找不到则为 `0` 并记 warning |
| SKU `pcs_qty` | `1` |
| 规格名 / 商品 `spec_models` | `singles` 拼接，例：`单品甲×2+赠1+单品乙×3` |

每个 `singles` 写一条拆解规则：

- `source` = 套餐唯一 sku
- `target` = `singles.product_id` 对应单品的默认规格
- `quantity_ratio` = `number + gift_number`（至少为 1）
- `rule_type` = `2`（组合套装拆解）

套餐组成变更（数量变 / 换基础单品 / 删除某项）：

- 数量、规格名、商品主数据：再次同步会更新
- 已不在 `singles` 中的旧拆解规则：同步时 **停用并软删**

## 6. 映射表约定（`hspsi_goods_source_mapping`）

| 字段 | 说明 |
| --- | --- |
| `source_id` | `hspsi_sys_data_source.id`（code=`huashu_home`） |
| `source_type` | `STANDARD` / `COMBO` |
| `source_goods_id` | 华溯 SPU id 字符串 |
| `source_sku_id` | 华溯 SKU id；套餐固定 `"0"` |
| `goods_id` / `sku_id` | 平台内部商品/规格 |
| `mapping_status` | `1=已映射`，`2=待确认`，`3=已停用` |
| 唯一键 | `(source_id, source_type, source_goods_id, source_sku_id)` |

套餐组成**不**拆成多行 `source_mapping`，拆解关系只写在 `hspsi_goods_sku_conversion_rule`。

---

## 7. 转换规则约定（`hspsi_goods_sku_conversion_rule`）

| `rule_type` | 含义 | 场景 |
| --- | --- | --- |
| `1` | 一对一替换 | 带 `mapping` 的单品 B → 真实品 A 默认规格 |
| `2` | 组合套装拆解 | 套餐 sku → 多个 singles 默认规格 |

| `status` | 含义 |
| --- | --- |
| `1` | 启用 |
| `2` | 停用 |

唯一键：`(source_goods_id, source_sku_id, target_goods_id, target_sku_id)`

## 8. 环境与前置条件

`.env`：

```env
HUASU_HOME_BASE_URL="https://xxx"
HUASU_HOME_APP_PUBLIC_KEY="-----BEGIN PUBLIC KEY-----
...
-----END PUBLIC KEY-----"
```

注意：

1. 修改 `HUASU_HOME_GOODS_CATEGORY_ID` 为实际叶级分类 id
2. 平台单位表建议存在名称为「套」的单位
3. `BASE_URL` 尾部斜杠会自动去除，避免路径出现 `//hspsi`
