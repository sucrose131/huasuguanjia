## POST 用户列表

POST /hspsi/user/list

> Body 请求参数

```json
{
  "page": 1,
  "page_size": 100,
  "id": 0
}
```

### 请求参数

|名称|位置|类型|必选|中文名|说明|
|---|---|---|---|---|---|
|» page|body|integer| 是 | 页码|none|
|» page_size|body|integer| 是 | 每页数量|默认100条，最大1000条|
|» id|body|integer| 是 | 最小用户ID|获取大于当前ID的用户数据|
