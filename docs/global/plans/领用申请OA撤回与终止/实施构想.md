# 领用申请（借用/OA 渠道）撤回与终止 实施构想

> 状态：代码完成待验收（2026-09-07 业务拍板 A1–F 已确认）
> 对应实施记录：`docs/daily/2026-09-07/领用申请OA撤回与终止实施记录.md`

## 一、业务规则与范围（已确认口径 A1–F）

- **范围（F）**：本期只做 OA 渠道（借用单，`draw_type=2`）的创建人撤回/终止；非借用（直接领用等，系统内自动通过）不在本期。
- **操作人（C1）**：仅**领用人本人**（单据领用人 `applicant_id` = 操作人在该单据账套下的 OA 员工身份），不是"创建人"（直接领用出库反向生成的借用单创建人是仓库操作人，无权操作）。
- **双入口（A1/A4，与采购申请一致）**：
  - **撤回**：撤销 OA 在途流程 → 单据回草稿（`status=0/approve_status=0`），可修改后重新提交；重新提交 OA 成功时**撤销撤回自动生成的待确认退回单（B2）**。
  - **终止**：撤销 OA 在途流程 → `approve_status=3` 终态，不可编辑/重提/删除。
- **先出库后审批的单据（B1/B2）**：若该借用单由直接领用出库反向生成且出库已生效（`comfirm_status=1`），撤回/终止都**自动生成待确认退回单追回物资**（复用驳回路径，`exit_reson` 与 `relation_kind` 区分来源）；出库未生效（`comfirm_status=0`）时拦截（与现有否决守卫一致）。
- **失败语义（E，沿用采购）**：OA 撤销失败 → 抛错，单据保持审批中可重试；OA 已撤销（重试场景）视为成功；OA 取消回调晚到且本地已撤回成草稿 → 不覆盖草稿（幂等）。
- **回调对齐（A3/D3）**：OA `CANCELED` 回调落 `approve_status=3`（原并入 2=驳回），0 号操作人写入带渠道标识，前端复用 `approval-status.ts` 区分"OA已取消/已取消"。
- **统计口径（D2，与采购一致）**：待审批=approve0 且 status1；已通过=approve1；驳回(2)/取消(3)不进桶；页面顶部统计复用采购同款 summaryLabels。
- **待办（D1，与驳回一致）**：撤回/终止/取消回调均关闭 `draw_approve` 待办；审批通过仍走 `syncApprovedRequisitionTodos`。
- **留痕（A5）**：沿用覆盖式 `approve_comment`，不新增历史表。

## 二、界面方案（沿用采购申请交互）

领用申请单列表行操作在"通过/驳回"前新增两枚按钮（仅列表页，无新页面/表单字段）：

| 按钮 | 出现条件（前端） | 确认文案 | 点击结果 |
| --- | --- | --- | --- |
| 撤回（warning） | 领用人本人 && drawType=2 && status=1 && approveStatus=0 | "撤回后将撤销OA审批，单据回到草稿可修改后重新提交；若已直接领用出库将同时生成待确认退回单" | toast：领用申请已撤回（已出库时提示已生成待确认退回单） |
| 终止（danger） | 同上 | "终止后将撤销OA审批并结束单据，不能再编辑或提交" | toast：领用申请已终止（已出库时提示已生成待确认退回单） |

审批状态列文案沿用共用 `approvalStatusText`：approve3 + OA 渠道（approve_by=0）→ "OA已取消"，本系统终止 → "已取消"。
页面顶部新增与采购一致的统计：申请单总数 / 待审批数 / 已审批数。

## 四、API 与事务设计

- 服务编排（镜像采购）：
  1. `revokeApplicantPendingOa`（事务外）：校验单据存在 → 领用人身份（`resolveApplicantIdentity` 按单据 org 账套）→ drawType=2 → 审批中(1/0) → 查最近 OA 实例：`PENDING_PUSH` 拦截；`RUNNING/BACKTOSTART` 调 `cancelRemoteProcess`（以领用人 OA 身份 `outer_ref_id` 调薪福通 `dealProcess(cancel)`，busKey 定位，已撤销视为成功，其余失败抛"撤销OA审批失败：原因"）。
  2. 事务内：行锁 + 二次校验 → 落本地账（撤回回草稿 / 终止置3）→ 关闭待办 → 直接出库已生效则 `ensureRejectedDirectOutputReturn` 生成待确认退回单 → 实例置 `CANCELED`。
- 回调 `handleOaApprovalResult`：`PASSED→1 / CANCELED→3 / REJECTED·DELETED→2`；`withdrawnLocally`（CANCELED && 草稿0/0）判重复不覆盖；取消同终止做直接出库追回与待办关闭。
- B2：`saveApplication` 提交 OA 成功与 `/submit-oa`（改走 service）成功后，按 `relation_kind='withdraw_return'` 且 `comfirm_status=0` 软删退回单并移除文档链。
- 幂等：重复撤回（已回草稿）直接返回成功；重复终止（已3）报"已取消，不能重复终止"；回调重复幂等沿用。
