# 停业组织业务隔离实施方案

## 一、业务规则

- `hspsi_basic_organization.operation_status = 1` 表示正常营业，可用于新业务；
- 停业组织不得出现在通用组织业务选项中；
- 不得在停业组织下新增或修改仓库；
- 停业前形成的组织、仓库、单据和追溯记录继续保留并允许历史查询；
- 前端选项过滤只改善操作体验，后端保存接口必须执行最终校验。

## 二、界面与交互

- 新增仓库页面的“所属组织”仅显示正常营业组织；
- 基础资料页面的“所属组织/所属公司”查询条件和新增、编辑表单统一使用可搜索树形选择器；
- 组织树按 `parent_id` 展示层级，节点只显示组织名称；输入名称关键字时过滤并定位匹配组织；
- 公司资料的“上级公司”使用相同树形选择器，并保留“顶级公司”节点；
- 采购申请列表的所属组织筛选和新增、编辑表单使用相同的可搜索组织树，选择后继续按原逻辑联动申请部门和目标仓库；
- 库存调拨单的调出组织、调入组织使用相同的可搜索组织树，分别联动调出仓库、调入仓库，并保留同类型仓库调拨校验；
- 其余可操作的组织筛选和业务表单统一使用可搜索组织树，包括采购订单、临时采购入库、采购付款、库存查询、库存盘点、库存报损/报盈、通用入出库、生产临时出库、实验室临时出库、BOM、销售订单和系统用户；
- 来源单据自动带出、收付款结果展示等不可操作的组织字段继续保持只读，不增加无意义的树形交互；
- 组织停业后，无须刷新或删除历史仓库数据；重新打开新增仓库页面时不再显示该组织；
- 通过旧页面缓存或直接请求提交停业组织时，提示“所属组织已停业，不能新增或修改仓库”。

## 三、字段与接口映射

| 页面/业务字段    | API字段                                    | 数据库来源                                  | 规则                               |
| ---------------- | ------------------------------------------ | ------------------------------------------- | ---------------------------------- |
| 所属组织选项     | `GET /api/base-data/organizations/options` | `hspsi_basic_organization.operation_status` | 仅返回 `1` 且未删除的数据          |
| 组织树父级关系   | `raw.parentId`                             | `hspsi_basic_organization.parent_id`        | `0` 为顶级；BigInt ID 按字符串传输 |
| 基础资料所属组织 | `orgId`                                    | 各基础资料表的 `org_id`                     | 选择树节点后按既有接口提交         |
| 采购申请所属组织 | `orgId`                                    | `hspsi_purchase_approve.org_id`             | 选择树节点后提交，并联动部门、仓库 |
| 调拨单调出组织   | `orgId`                                    | `hspsi_inventory_transfer.org_id`           | 选择树节点后联动调出仓库           |
| 调拨单调入组织   | `toOrgId`                                  | `hspsi_inventory_transfer.to_org_id`        | 选择树节点后联动同类型调入仓库     |
| 其他业务所属组织 | `orgId`                                    | 各业务主表既有 `org_id`                     | 仅替换选择控件，保留原接口和联动   |
| 公司上级组织     | `parentId`                                 | `hspsi_basic_organization.parent_id`        | 选择“顶级公司”时提交 `0`           |
| 仓库所属组织     | `orgId`                                    | `hspsi_basic_warehouse.org_id`              | 保存前校验对应组织正常营业         |

不新增数据库表、字段或字典。

## 四、验收标准

1. 停业组织不出现在新增仓库的组织下拉框；
2. 直接向仓库新增或修改接口传入停业组织时，后端拒绝保存；
3. 正常营业组织仍可新增仓库；
4. 历史组织、仓库和业务数据仍可查询。
5. 基础资料的组织筛选及表单字段可按层级展开，并可按组织名称搜索；节点标签不拼接组织编号。
6. 所有可操作组织控件使用统一树形搜索交互；来源锁定、查看态及其他原有禁用条件保持有效。
