# 领用出库数量口径与编辑约束

## 1. 业务口径

- 申请数量：来源领用申请明细的 `draw_qty`。
- 历史已出：除当前出库单外，当前申请明细累计已确认的实际出库数量。
- 剩余可出：`申请数量 - 历史已出`，与商品是否可归还无关。
- 当前出库数量：当前出库草稿明细的 `fact_draw_qty`。
- 库存可用数量：所选组织、仓库、商品、SKU、批次的实时库存可用量。
- 页面允许的最大出库数量：`min(剩余可出, 所选批次库存可用数量)`。
- 已退数量和剩余可退仅用于领用退回，不得复用为历史已出和剩余可出。

## 2. 字段与数据映射

| 页面字段 | API 字段 | 数据来源/计算 | 数据库字段 |
| --- | --- | --- | --- |
| 申请数量 | `applicationQty` | 来源申请明细 | `hspsi_draw_approve_detail.draw_qty` |
| 历史已出 | `historicalQty` | 其他已确认出库明细累计 | `hspsi_draw_approve_output_detail.fact_draw_qty` |
| 剩余可出 | `remainingQty` | `applicationQty - historicalQty` | 计算字段，不写库 |
| 当前出库数量 | `quantity` | 当前出库明细 | `hspsi_draw_approve_output_detail.fact_draw_qty` |
| 已退数量 | `returnedQty` | 当前出库明细的已确认退回累计 | `hspsi_draw_approve_output_exit_detail.exit_qty` |
| 剩余可退 | `returnableRemainingQty` | 可归还时 `quantity - returnedQty` | 计算字段，不写库 |
| 批次库存可用量 | `inventoryQty` | 库存批次选项 | 现有库存结存表计算结果 |

## 3. API 与交互约束

- `GET /requisitions/outputs/:id` 必须分别返回出库口径和退回口径字段。
- 编辑出库草稿时，按单据组织和仓库重新加载库存批次，不使用跨仓库库存快照。
- 剩余可出大于 0 时允许编辑出库数量；选择批次后同时受批次库存上限约束。
- 后端保存继续校验申请剩余数量，确认出库继续执行实时库存校验。
- 不新增表、字段或字典，不修改现有业务数据。

## 4. 验收标准

- `DRO20260827000003` 显示申请 3、历史已出 0、剩余可出 3、当前出库 3。
- 选择库存 14 的批次后，最大可出仍为 3，输入框可编辑。
- 无需归还商品的剩余可出不再被错误置为 0。
- 领用退回仍按已退数量和剩余可退数量限制。
